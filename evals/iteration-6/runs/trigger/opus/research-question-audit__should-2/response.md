# 研究問題稽核報告

## 稽核對象
「我想研究遠距工作對員工工作滿意度的影響」

## 檢查點 A：研究缺口分類
**判定：未通過**

**理由：** 你目前只說了想研究什麼，沒有說明文獻還缺什麼。這個題目要特別小心，因為遠距工作和工作滿意度的關係早就有很多人做過了。例如 Gajendran 與 Harrison（2007）做過統合分析，Golden 與 Veiga（2005）也提出遠距程度和滿意度之間可能是曲線關係。COVID 之後相關研究又大量增加。所以你必須明確指出缺口是哪一種：
- **證據缺口**：文獻結果互相矛盾，例如有人發現正向效果，也有人發現不顯著或曲線關係。這個方向可能最有機會。
- **情境缺口**：如果理由是「台灣還沒人做」或「後疫情還沒人做」，這不算情境缺口。你要補齊兩件事：原理論依賴哪一條假設，以及台灣或後疫情的哪個特性推翻了它。

## 檢查點 B：收斂程度
**目前所在層次：子題，還沒到題目層**

**建議：** 「遠距工作」這個概念太籠統，至少要先決定以下兩件事：
- 自變數怎麼定義：有沒有遠距（二分）、每週遠距幾天（強度），還是完全遠距和混合工作的比較？
- 對象是誰：哪個產業、哪種職務、哪個國家或地區？

## 檢查點 C：題目定案六問
1. **一句話講清楚：不通過。** 「影響」沒有講方向和形狀：是正向、負向，還是曲線？
2. **有人在乎：通過，但有條件。** 企業的人資部門和政策制定者確實關心，但你要講出他們拿到答案後會做什麼決定。例如「每週開放幾天遠距最適當」，這比泛泛說「有影響」更有用。
3. **缺口分類明確：不通過。** 理由同檢查點 A。
4. **依變數清楚：通過。** 工作滿意度是成熟的構念，有既有量表可以用，例如 MSQ、JDI。
5. **資料可得性：不確定。** 你還沒說明樣本從哪裡來，也還沒確認能不能接觸到有遠距經驗的員工。
6. **兩年可行＋降級方案：不確定。** 問卷研究本身做得完，但你還沒提出降級方案。

## 檢查點 D：壞題目長相比對
**命中：**
- **③ 變數沒有理論來源（部分命中）：** 依變數有理論基礎，但「遠距為什麼會影響滿意度」的機制沒有任何理論支撐。可能的理論有工作要求－資源模型（JD-R）、自我決定理論（自主性）、邊界理論（工作與家庭界線）等，但你還沒選。
- **⑤ 換個名詞就是別人的論文（高風險）：** 如果只做「遠距 → 滿意度」的直接效果，和既有研究幾乎一樣，不容易說出新的問題意識。
- **⑥ 不可否證（高風險）：** 「影響」沒有方向，不管結果是正、負還是沒有顯著差異，都能說成「有發現」。

## 檢查點 E：句型與常見錯誤
**句型判定：不符合。** 現在的寫法是主題描述，不是研究問題句。量化版本可以改成這樣：「遠距工作強度對員工工作滿意度的預測效果為何？」

**是非問句紅線：** 不適用，因為目前還不是問句。改寫時要避免寫成「遠距工作是否影響工作滿意度？」

**常見錯誤命中：**
- **第 5 條，變數缺乏可辨識定義：** 「遠距工作」還沒有操作型定義。
- **第 7 條，問題句寫成目的句：** 「我想研究 X 對 Y 的影響」是目的，不是可以被回答的問題。

## 檢查點 F：一致性檢查鏈
- **目的 → 問題：** 目的大致有了，但還沒收斂成問題。
- **問題 → 假說、假說 → 架構、架構 → 分析、分析 → 結論：** 資訊不足以判斷。還缺研究問題句、假說（含方向）、研究架構和分析方法。

## 檢查點 G：對抗式審查
1. **價值審查：** 如果只是證明「遠距會讓人比較滿意」，對實務的價值有限。能指出「在什麼條件下」或「透過什麼機制」，企業才有辦法據此調整制度。

2. **理論解構：** 這個研究隱含一個假設：遠距是「原因」、滿意度是「結果」。但也可能是滿意度高或條件好的員工比較會選擇遠距，也就是自我選擇或反向因果。如果這個假設不成立，「影響」兩個字就站不住。

3. **方法論審計：**
   - **方法類型：** 方法和問題型態大致相符，應該會用量化問卷。
   - **因果宣稱：** 單一時間點蒐集的問卷資料撐不起因果宣稱，措辭要從「影響」降成「預測」或「關聯」，除非改用縱貫設計或準實驗設計。
   - **抽樣：** 如果用便利抽樣，例如透過社群網路發問卷，樣本會偏向特定產業或年齡層，要誠實寫出限制。
   - **測量：** 工作滿意度可以用既有量表；遠距的測量方式要另外交代。

4. **可行性與備胎：** 主研究可以設計成「遠距強度 → 中介變數 → 滿意度」。如果中介變數的資料不理想，降級方案是只檢驗直接效果，加上組間比較（完全遠距、混合、完全進辦公室）。

5. **具體建議：**
   - 先找 2 到 3 篇遠距和滿意度的回顧或統合分析，確認文獻結論哪裡不一致。
   - 選一個理論機制，把題目從直接效果升級成中介或干擾模型，例如「遠距強度透過工作自主性影響滿意度」，或「家庭負擔干擾遠距對滿意度的效果」。
   - 確認你能接觸到的樣本來源。
