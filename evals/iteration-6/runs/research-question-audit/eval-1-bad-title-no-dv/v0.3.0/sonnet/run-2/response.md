# 研究問題稽核報告

## 稽核對象
「探討台灣中小企業導入AI客服系統之研究」

## 檢查點 A：研究缺口分類
判定：**未通過**
理由：題目本身只給出「地理＋產業」的新穎性宣稱（台灣、中小企業），沒有指名屬於證據／知識／方法／理論／情境五種缺口的哪一種。若你心裡想的是「情境缺口」（例如：某個技術採納理論在其他情境驗證過，但中小企業情境特殊），紅線判定要求你補齊兩欄：(1) 原理論依賴的哪一條假設，(2) 被中小企業情境的哪一個特性推翻。目前這兩欄都是空的——「台灣還沒人做」不構成情境缺口。

## 檢查點 B：收斂程度
目前所在層次：**主題／子題層**，尚未到達「題目」或「研究問題」層。
建議：目前只描述了一個研究領域範圍（AI客服系統在中小企業的導入），還沒有講清楚「要測量或回答什麼」。需要先問自己：導入的「前因」（意願？決策因素？）還是「後果」（效益？績效？顧客滿意度？）？還是「歷程」（怎麼導入的、遇到什麼障礙）？這三個方向會導向完全不同的依變數與研究設計。

## 檢查點 C：題目定案六問
1. 一句話講清楚：**不通過** — 讀者看完題目仍不知道你要問「意願」「效益」「障礙」還是「歷程」。
2. 有人在乎：**不確定** — 中小企業主、AI服務廠商、政府中小企業輔導單位理論上都可能在乎，但你目前講不出「拿到答案之後，這些人具體會做什麼決定」。
3. 缺口分類明確：**不通過**（同檢查點 A）
4. 依變數清楚：**不通過** — 題目沒有依變數，是「⋯⋯之研究」句型（見檢查點 D①）。
5. 資料可得性：**不確定** — 不知道是要發問卷給中小企業主、訪談導入過的企業，還是用次級資料，資料設計未定就無法判斷可得性。
6. 兩年可行＋降級方案：**不確定** — 範圍未收斂前無法評估工作量，也還沒有降級方案。

## 檢查點 D：壞題目長相比對
命中：**①沒有依變數的「⋯⋯之研究」** — 題目停在描述一個主題領域，看不出要測量或回答什麼具體結果。這是六種壞題目長相裡最典型、也最常見的一種。
其餘 ②③④⑤⑥：目前資訊不足以判斷（沒有具體變數、資料設計、理論框架可供比對），但這些通常要等你把①解決、收斂出具體研究問題後才能真正檢查。

## 檢查點 E：句型與常見錯誤
句型判定：目前不是一個「研究問題」，而是一個「主題描述句」，尚無法對應量化／質性／DSR 任何一種標準句型。
是非問句紅線：不適用（目前連問句都還不是）
常見錯誤命中：**第7條「問題句寫成目的句」**——「探討⋯⋯之研究」本質上是「本研究旨在探討⋯⋯」的變形，是目的描述，不是一個可以被回答的問句。

## 檢查點 F：一致性檢查鏈
資訊不足以判斷。目前只有題目本身，沒有研究目的、研究問題、假說、研究架構等後續資訊，無法檢查目的→問題→假說→架構→分析→結論這條鏈是否咬合。

## 檢查點 G：對抗式審查
1. **價值審查**：潛在關心對象存在（中小企業主、AI客服廠商、政策制定者），但你目前答不出「他們拿到答案後會做什麼具體決定」——這通常要等依變數確定後才能講清楚。
2. **理論解構**：完全未指名支撐理論。如果你打算用技術採納類理論（如 TAM、UTAUT）或組織層次的 TOE 架構，這些理論本身依賴哪些假設（例如「決策者有自由選擇權」「決策基於理性評估」），在中小企業情境下是否成立，都還沒被檢驗過。
3. **方法論審計**：無法判斷，因為研究方法（問卷／訪談／次級資料）與研究取向（量化／質性）都尚未確定，這些必須等依變數與研究問題定案後才能評估。
4. **可行性與備胎**：範圍未收斂，暫時無法評估兩年是否做得完，也還沒有降級方案。
5. **具體建議**：下一步不是急著查文獻找理論，而是先回答一個問題——「你比較想知道『為什麼中小企業導入或不導入 AI 客服』，還是『導入之後產生了什麼效果』？」這個選擇會決定你接下來要找什麼理論、設計什麼研究方法。

## 預期質詢清單
- （檢查點 A）「除了『台灣中小企業還沒人做過』之外，這個情境有什麼特性會讓原本的理論預測不成立？」
- （檢查點 C-1／D①）「你的依變數具體是什麼？如果只能選一個可以測量的東西，會是什麼？」
- （檢查點 C-2）「這個研究的答案，具體是誰會拿去做什麼決定？」
- （檢查點 C-5）「你打算怎麼蒐集資料？樣本從哪裡來，預估能拿到多少家企業的回應？」
- （檢查點 C-6）「兩年內做得完嗎？如果做不完，你的縮小版方案是什麼？」
- （檢查點 E）「你的研究問題可以怎麼改寫成一句能被回答的問句，而不是『探討⋯⋯之研究』這種目的描述？」
- （檢查點 F）「你的研究目的、研究問題、假說、研究架構之間，變數名稱一致嗎？」
- （檢查點 G-2）「你打算用什麼理論解釋中小企業的導入行為？這個理論的哪一條假設在中小企業情境下可能站不住？」

**需重新收斂** — 目前這是一個主題描述，還沒有收斂成一個具體的研究問題。最關鍵的缺口是沒有依變數（檢查點 D①）與沒有指名研究缺口類型（檢查點 A），這兩項不解決，後面的方法設計、資料蒐集都無從談起。
