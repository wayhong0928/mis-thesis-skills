# 研究問題稽核報告

RQ1：大學生的科技焦慮是否正向預測其生成式AI求助頻率？

背景：橫斷面問卷，約 250 人，依據壓力因應理論，控制性別與年級。

理由：你沒有說明這組關係屬於證據／知識／方法／理論／情境缺口中的哪一種。從背景資訊推測，最可能的候選是「知識缺口」（科技焦慮、程式設計自我效能與生成式AI求助頻率三者的關係，因為生成式AI是新興現象，很可能尚未被直接檢驗過），但這是我的推測，不是你已確認的定位。若你打算主張「情境缺口」（例如「這個理論還沒在大學生／生成式AI情境驗證過」），要注意紅線：必須同時交代「原理論依賴的哪一條假設」與「被本情境的哪一個特性推翻」，不能只說「還沒人做過」。

## 檢查點 D：壞題目長相比對

## 檢查點 E：句型與常見錯誤
句型判定：符合量化研究常見句型的預測效果類型，方向大致對。

**是非問句紅線**：
- RQ1：勉強通過 — 「是否正向預測」已指出方向（正向），符合 SKILL 判準中列為可接受的括號寫法。
- RQ2：**不通過** — 「是否影響」是典型的是非問句，沒有指出效果方向，命中紅線範例本身（「X 是否影響 Y？」被明確列為不合格例句）。建議改寫為「程式設計自我效能是否負向（或正向）預測生成式AI求助頻率？」或「程式設計自我效能對生成式AI求助頻率的預測效果為何？」——但改寫前要先想清楚方向該怎麼假設（見檢查點 G-2）。

- 第 5 條（變數缺乏可辨識定義）：三個變數都需要補上操作型定義／對應量表，目前句子本身看不出要測量什麼具體指標。
- 其餘 6 條未命中或資訊不足以判斷（尚未提供假說、架構、分析計畫）。

## 檢查點 G：對抗式審查
1. **價值審查**：可能在乎的對象包括大學教學單位、學輔中心、通識課程設計者——若科技焦慮確實正向預測求助頻率，可能支持「先降低焦慮再推廣工具」的介入設計；若自我效能有顯著（正或負）效果，則可支持「先建立程式基礎能力」或「反而要鼓勵低自信者多用 AI 工具」等不同介入方向。但這個用途目前是我的推測，你需要在論文中明講。

2. **理論解構（關鍵假設）**：壓力因應理論假設「壓力源經評估後觸發因應行為」，這裡隱含的關鍵假設是「生成式AI求助」屬於一種問題焦點因應策略（problem-focused coping）。但這條假設可能不成立：求助頻率也可能是逃避型因應（avoidance coping）的展現，或甚至是焦慮的結果而非獨立於評估過程之外的行為。更關鍵的是，**RQ2 的方向在理論上是模糊的**：自我效能高的學生，可能因為「更懂得善用工具」而更常求助 AI（正向路徑），也可能因為「自己就能解決問題、不需要外部協助」而更少求助（負向路徑）。這兩條路徑在壓力因應理論下都講得通，你必須在文獻回顧中選定一條並提出理由，否則審查委員會直接問你「所以你預期的方向到底是什麼、為什麼」。

3. **方法論審計**：
   - 方法類型與問題型態相符：通過，量化預測型問題搭配問卷調查與迴歸分析是合適的配對。
   - 抽樣是否撐得住宣稱：不確定 — n=250 對於 4 個預測變數（科技焦慮、自我效能、性別、年級）的迴歸而言，樣本量本身足夠；但你沒有說明是單一校或多校、機率或便利抽樣，這會直接限制你能宣稱的推論範圍（例如只能推論到該校，不能推論到「大學生」母體）。
   - 測量工具是否恰當：不確定 — 「生成式AI求助頻率」很可能是新構念（生成式AI問世時間短），若是自編量表，需要報告內容效度、收斂／區辨效度、Cronbach's α；若科技焦慮與程式設計自我效能採用既有量表，也要交代出處與原始信效度數據。目前資訊都未提供。
   - **橫斷面設計與「預測」用詞的落差**：這是最需要注意的一點。橫斷面資料無法確立時間先後順序，「求助頻率高導致焦慮降低」與「焦慮導致求助頻率高」在統計上難以區分（反向因果）。若研究問題持續使用「預測」一詞，建議在方法限制中明確聲明這是統計預測（statistical prediction）而非因果推論，並在討論中承認反向因果的可能性，否則會被質疑「橫斷面設計憑什麼講預測」。

4. **可行性與備胎**：n=250 橫斷面問卷在一般碩士論文時程內可行，風險低。備案：若回收不足 250，可考慮跨班級／跨學期合併施測，或縮小為單一 RQ（例如先確認 RQ1 主效果，RQ2 作為探索性附加分析）。

5. **具體建議**：
   - 先明確指名研究缺口類型（知識缺口的可能性最高），並補上「誰會用這個答案」的具體陳述。
   - 改寫 RQ2 為非是非句型，並先透過文獻決定自我效能對求助頻率的預期方向（正向或負向），再回頭定句子。
   - 在理論回顧中明確論證「程式設計自我效能」在壓力因應理論中的角色定位（因應資源／次級評估），不要只掛theoretical framework 的名稱而不交代路徑。
   - 補齊三個變數的操作型定義與測量工具來源（既有量表或自編，自編需報告信效度）。
   - 說明抽樣方式（單一校／多校、機率／便利抽樣），並在限制中誠實交代代表性範圍。
   - 在方法限制中明確處理橫斷面設計與「預測」用詞之間的因果推論落差，並討論反向因果的可能性。
   - 考慮是否要把 RQ1、RQ2 合併寫成一個 RQ（同一個迴歸模型、兩個預測變數），會比目前兩題並列更貼近你實際會跑的統計分析。
