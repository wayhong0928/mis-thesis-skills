# 研究問題稽核報告

## 稽核對象
「研究生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：不確定
理由：你目前只講了「想研究什麼」，沒有講「為什麼值得研究」——沒有指出現有文獻在這個關係上是證據矛盾（證據缺口）、完全空白（知識缺口）、方法有限制（方法缺口）、理論解釋不足（理論缺口），還是某個情境假設會被推翻（情境缺口）。生成式AI對學習的影響目前是熱門題目，文獻量其實不少，需要你先盤點過既有研究，才能指名屬於哪一種缺口。

## 檢查點 B：收斂程度
目前所在層次：介於「主題」與「子題」之間
建議：你已經鎖定母體（大學生）與自變數（生成式AI使用），這比單純的「主題」層更進一步，但還沒收斂到「題目」層——因為依變數同時列了四個（學習動機、學習成效、批判思考能力、未來就業意願），還沒決定要聚焦哪一個或哪一組。收斂方向建議見下方檢查點 D。

## 檢查點 C：題目定案六問
1. 一句話講清楚：不通過 — 四個依變數要一句話講完，勢必要拆成三、四個子句才講得清楚，代表題目還沒收斂。
2. 有人在乎：不確定 — 教師、教學單位、政策制定者可能會在乎，但因為範圍太廣，還講不出「拿到答案之後具體能做什麼決定」。
3. 缺口分類明確：不確定 — 呼應檢查點 A，尚未指名。
4. 依變數清楚：不確定 — 四個依變數的名稱都給了，但都還沒有操作型定義（例如「學習成效」是指測驗成績、GPA，還是自評量表？「批判思考能力」用什麼工具測？）。
5. 資料可得性：不確定 — 你還沒提供資料來源、抽樣方式或所需樣本規模的資訊。
6. 兩年可行＋降級方案：不確定 — 尚未提供時程規劃，但先預告：四個依變數若都要用經驗證量表施測並分別建立理論路徑，碩士兩年容量吃緊的機率偏高（詳見檢查點 D）。

## 檢查點 D：壞題目長相比對
命中：**②戰線過長**

判斷依據：學習動機、學習成效、批判思考能力、未來就業意願這四個依變數，**不是同一個構念的不同指標**，而是各自需要獨立理論脈絡支撐的結果：
- 學習動機 → 通常掛自我決定理論、期望價值理論等
- 學習成效 → 通常掛認知負荷理論、學習表現相關文獻
- 批判思考能力 → 通常掛獨立的認知心理學量表（如 CCTST）與其理論脈絡
- 未來就業意願 → 通常掛生涯發展理論、計畫行為理論等

四條路徑各自要有文獻回顧、理論假說、測量工具，碩士論文篇幅通常撐不住四套完整的理論論證。此外，這四者對生成式AI的反應方向可能還互相矛盾（例如過度依賴AI可能提升學習動機、卻削弱批判思考能力），這一點目前也還沒被討論到。

其餘五種未命中（依變數存在、變數尚看不出憑空發明、資料可得性未知但非直接判定不可得、題目尚不算完全照搬既有研究但也未確認新穎性、題目具備可否證的潛力）。

## 檢查點 E：句型與常見錯誤
句型判定：不適用 — 你目前寫的是研究**目的**敘述（「想研究…的影響」），還不是正式的研究問題句。
是非問句紅線：不適用（同上，還沒到寫研究問題句的階段）。
常見錯誤命中：
- **第7條「問題句寫成目的句」**：目前整段是目的描述，還沒轉成可回答的問句。
- **第2條「一題塞進多條因果路徑」**：同一句話裡塞了四個依變數，呼應檢查點 D 的②。

## 檢查點 F：一致性檢查鏈
目前只有研究目的的雛型，研究問題、假說、架構、分析方法都還沒提供，因此「問題→假說」「假說→架構」「架構→分析」「分析→結論」四環皆為**資訊不足以判斷**。建議先完成檢查點 D 的收斂，再往下發展假說與架構，這條鏈才有東西可以稽核。

## 檢查點 G：對抗式審查
1. **價值審查**：大學教學單位、課程設計者、政策制定者可能關心生成式AI對學習的影響，但因為題目同時涵蓋動機、成效、批判思考、就業意願四個面向，讀者很難判斷「拿到答案之後，具體要調整哪一項教學政策」——範圍越廣，行動指向越模糊。
2. **理論解構**：隱含假設是「生成式AI使用會透過某種一致機制同時影響這四個結果」，但這個假設本身值得質疑——例如過度依賴生成式AI完成作業，可能短期內提升學習動機與成效（因為降低挫折感），卻同時削弱批判思考能力（因為減少獨立思辨的機會），對就業意願的影響方向則可能完全取決於學生對AI技能的自我效能感。四者的因果方向不一定同向，這一點目前研究想法裡沒有處理。
3. **方法論審計**：若採量化問卷，需要四套具備信效度佐證的量表（學習動機、學習成效、批判思考能力、就業意願），加上生成式AI使用的操作型定義（是使用頻率？特定工具如ChatGPT？用途類型如寫作輔助vs.程式除錯？）。目前這些都還沒界定，無法判斷方法是否撐得住。
4. **可行性與備胎**：四個依變數、四套理論路徑、四套量表要在碩士兩年內完成資料蒐集與分析，時程風險偏高；目前沒有降級方案。
5. **具體建議**：
   - 先從四個依變數中選出 1 個（最多 2 個且彼此有明確理論關聯，例如學習動機與學習成效常被同一套動機理論串起來）作為主要依變數，其餘可以留作討論或未來研究方向。
   - 明確化生成式AI的操作型定義（用什麼工具、什麼使用行為、量測使用頻率還是使用方式）。
   - 盤點近三年文獻，確認你想切入的缺口類型（證據矛盾？完全空白？方法限制？），把這一步做完才有辦法過檢查點 A。
