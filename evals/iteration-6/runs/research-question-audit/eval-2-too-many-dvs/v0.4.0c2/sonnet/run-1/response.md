# 研究問題稽核報告

## 稽核對象
「生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：不確定
理由：使用者尚未說明這個題目屬於證據／知識／方法／理論／情境缺口的哪一種。生成式AI與大學生學習的關聯目前已有不少文獻（並非完全空白），也不確定是「證據矛盾」還是「方法限制」還是其他類型。需要先去查文獻，確認目前哪個環節（哪個依變數、哪個理論路徑）尚未被回答，才能指名缺口類型。

## 檢查點 B：收斂程度
目前所在層次：介於「子題」與「題目」之間
建議：技術（生成式AI）、母體（大學生）都已收斂，但依變數端還停在「列出四個我都想看」的階段，尚未收斂成一個可以一句話講完、有明確理論路徑的研究問題。建議先決定「這四個依變數之間的關係是什麼」（是平行各自獨立的四條線？還是有先後順序，例如動機→成效→批判思考的連鎖？），才能往下收斂。

## 檢查點 C：題目定案六問
1. 一句話講清楚：不通過 — 目前的敘述是「我想看 A、B、C、D 對這四件事的影響」，讀者聽完還是不知道你真正要問的「一個」問題是什麼，需要先收斂。
2. 有人在乎：通過 — 教學單位、課程設計者、學生本身、就業輔導單位都可能關心生成式AI對學習與就業意願的影響，這是有明確利害關係人的主題。
3. 缺口分類明確：不確定 — 見檢查點 A，資訊不足。
4. 依變數清楚：不通過 — 四個依變數（學習動機、學習成效、批判思考能力、未來就業意願）分別是四個不同的構念，各自需要一套理論解釋（動機可能對應自我決定論，批判思考有自己的評量架構，就業意願常見理論如計畫行為理論），目前沒有說明它們之間的關係，等於同時開了四條戰線。
5. 資料拿不拿得到：不確定 — 尚未說明要用問卷、量表還是次級資料，資訊不足。
6. 兩年可行＋降級方案：不通過 — 四個依變數各自要做文獻回顧、選定理論、找量表、驗證信效度，碩士論文的篇幅與時間很難同時撐住四套完整論證，目前也沒有提到若做不完要怎麼縮小範圍。

## 檢查點 D：壞題目長相比對
命中：② 戰線過長 — 學習動機、學習成效、批判思考能力、未來就業意願是四個各自需要獨立理論解釋的依變數，不是同一構念的不同指標（例如都用來測「學習投入程度」的話才不算），因此判定命中。每多一個依變數，就要多一套文獻回顧與假說推導，四套同時做在碩士論文的篇幅裡風險很高。

## 檢查點 E：句型與常見錯誤
句型判定：不適用 — 目前給的是研究目的的敘述（「我想研究⋯⋯」），還沒有寫成一句可以被回答的研究問題句，無法判斷屬於量化或質性句型。
是非問句紅線：不適用（尚未寫出研究問題句）
常見錯誤命中：
- 第2條「一題塞進多條因果路徑」— 同一句話裡塞了四條依變數路徑，讀者要拆成四句才看得懂到底在問什麼。
- 第7條「問題句寫成目的句」— 目前寫成「我想研究⋯⋯的影響」這種目的描述，而非一個可以被回答的問句，例如「生成式AI使用頻率對大學生學習動機的預測效果為何？」才是研究問題句的寫法。

## 檢查點 F：一致性檢查鏈
資訊不足以判斷各環。目前只有「研究目的的粗胚」，還沒有：
- 收斂後的正式研究問題句
- 對應的假說
- 研究架構圖（變數之間如何連接，是平行還是序列中介）
- 預計採用的分析方法
建議先把研究問題本身收斂出來，才有辦法往下檢查這條鏈是否環環相扣。

## 檢查點 G：對抗式審查
1. **價值審查**：教師、課程設計者、學生本人、就業輔導單位都可能在乎答案，但「能拿去做什麼決定」要看你最後聚焦在哪個依變數——例如若聚焦學習動機與學習成效，教師可以決定要不要調整課程設計中允許使用生成式AI的方式；若聚焦就業意願，職涯輔導單位可能藉此調整輔導內容。目前四個依變數同時存在，價值訴求會被稀釋，不易讓委員或讀者抓到「這篇論文到底想幫誰做什麼決定」。
2. **理論解構**：目前的敘述隱含一個假設——生成式AI的使用會「單向影響」這四個結果。但實際上可能存在反向因果（例如學習動機高的學生本來就更願意嘗試生成式AI，而不是生成式AI提升了動機），也可能有混淆變數（例如自我調節學習能力同時影響生成式AI使用行為與這四個結果）。如果採橫斷面問卷設計，這個因果方向的假設站不太住。
3. **方法論審計**：若你的問題型態是「有沒有關係、關係多強、能不能預測」，適合配量化方法（問卷調查）；但目前資訊不足以判斷你打算用什麼量表測量這四個構念、抽樣方式為何、樣本數是否足夠支撐四組迴歸或結構方程模型。這部分需要你補充後才能進一步審計。
4. **可行性與備胎**：四個依變數同時做完整的理論回顧、假說推導、量表驗證，對碩士論文而言時程壓力很大，目前沒有看到降級方案（例如「如果來不及，先只做動機與成效兩者的中介模型，批判思考與就業意願留待未來研究」）。
5. **具體建議**：
   - 先去查文獻，確認這四個依變數之間有沒有既有理論支持的因果或中介關係（例如「生成式AI使用 → 學習動機 → 學習成效」這種序列路徑，会比四個平行依變數更聚焦、也更符合單一理論框架）。
   - 選定一到兩個核心依變數作為主研究問題，其餘可以降為探索性、次要分析，或直接留給未來研究。
   - 把研究目的改寫成一句可回答的研究問題句，並確認句型有交代效果方向（不能是單純是非句）。
