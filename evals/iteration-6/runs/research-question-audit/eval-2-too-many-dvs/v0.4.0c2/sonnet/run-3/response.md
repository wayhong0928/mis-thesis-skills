# 研究問題稽核報告

## 稽核對象
「我想研究生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：不確定
理由：使用者尚未說明這個研究要補的是證據缺口、知識缺口、方法缺口、理論缺口還是情境缺口中的哪一種。目前只有「我想研究 X 對 Y 的影響」這個方向陳述，看不出是文獻結果矛盾（證據缺口）、根本沒人問過（知識缺口）、既有方法有限制（方法缺口）、理論解釋不完整（理論缺口），還是特定母體下某條理論假設會被推翻（情境缺口）。若使用者的貢獻論述是「生成式AI在台灣大學生身上還沒人研究過」，這屬於情境缺口的紅線不合格寫法，會被要求補齊「原理論依賴哪一條假設」與「被大學生／台灣情境的哪一個特性推翻」兩欄。

## 檢查點 B：收斂程度
目前所在層次：介於「主題」與「子題」之間
建議：已經指定了自變數（生成式AI使用）與一組依變數候選（學習動機、學習成效、批判思考能力、就業意願），但還沒有收斂出「題目」層級的具體研究問題句，也還沒指定理論框架、母體範圍、依變數之間的關係假設。下一步要先決定：這四個依變數要不要一起處理，還是選其中一到兩個作為核心，其餘降為背景變項或未來研究方向。

## 檢查點 C：題目定案六問
1. 一句話講清楚：不通過 — 目前的敘述包含四個依變數，讀者需要拆成四句才能確認到底要回答什麼，不符合「一句話講清楚」的要求。
2. 有人在乎：不確定 — 使用者尚未說明誰會用這個答案做什麼決定（例如大學教師調整教學設計、學校研擬AI使用政策、學生自我調節學習），需要補充。
3. 缺口分類明確：不通過 — 對應檢查點 A，尚未指名任一種缺口。
4. 依變數清楚：不確定 — 四個依變數的名稱都有列出，但「學習成效」「批判思考能力」這類構念常有多種操作型定義（例如學習成效是指成績、自我評估學習成果，還是學習投入），目前看不出使用者打算怎麼測量。
5. 資料可得性：不確定 — 尚未提供樣本來源、量表選用或母體規模的資訊。
6. 兩年可行＋降級方案：不確定，但風險偏高 — 四個依變數若各自需要獨立的理論鋪陳、假說與統計路徑，對碩士論文規模而言時程壓力大，且目前沒有看到降級方案。

## 檢查點 D：壞題目長相比對
命中：② 戰線過長

理由：學習動機、學習成效、批判思考能力、未來就業意願這四個依變數，分屬不同的理論脈絡——學習動機通常對應自我決定理論或期望價值理論，學習成效對應學習成果評量或認知負荷相關理論，批判思考能力對應批判思考技能發展的教育心理學文獻，未來就業意願則對應生涯發展或就業力（employability）理論。這不是同一個構念的四個測量指標（例如都在測「學習投入」的不同面向），而是四個各自需要獨立理論解釋、獨立文獻回顧、獨立假說與路徑分析的結果變項，符合「每多一個獨立結果就要多一套理論推導」的命中判準。

其餘五種（①③④⑤⑥）：目前資訊不足以判斷，非未命中，需使用者補充理論來源、資料來源與新穎性論述後才能確認。

## 檢查點 E：句型與常見錯誤
句型判定：不符合 — 目前的敘述是「我想研究…同時也想看…」，屬於目的描述句，不是一個可以被直接回答的研究問題句。
是非問句紅線：不適用（使用者還沒寫出正式研究問題句）
常見錯誤命中：
- 第 2 條「一題塞進多條因果路徑」：同一段敘述同時包含四條因果路徑（AI→動機、AI→成效、AI→批判思考、AI→就業意願）。
- 第 7 條「問題句寫成目的句」：整段是「本研究旨在探討」式的目的描述，尚未轉換成可回答的問句。

## 檢查點 F：一致性檢查鏈
資訊不足以判斷。使用者目前只提供了研究目的層級的描述，沒有正式研究問題、假說、研究架構或分析方法的資訊，因此「問題→假說」「假說→架構」「架構→分析」「分析→結論」這幾環都無法判斷是否咬合。

## 檢查點 G：對抗式審查
1. **價值審查**：不確定。生成式AI對學習的影響是目前教育研究的熱門題目，理論上校方、教師、教育政策制定者都可能在乎，但使用者尚未指明具體的利害關係人與他們會拿答案去做什麼決定，需要補充才能確認價值審查是否通過。
2. **理論解構**：不確定，取決於使用者選用的理論框架。如果採用科技接受模型或自我決定理論來解釋「AI使用如何影響動機」，關鍵假設可能是「學生對AI工具的自主使用意願會轉化為內在學習動機」——這條假設在AI可能被用於代寫作業、降低學生主動思考機會的情境下，未必成立，值得在文獻回顧階段先檢驗。
3. **方法論審計**：不確定。這類題目通常採問卷調查的量化路徑，但四個依變數若都要用信效度俱佳的既有量表測量，且要跑出四條獨立的迴歸或SEM路徑，對樣本數與分析複雜度的要求會顯著提高，需要使用者說明打算用的量表與樣本規模才能判斷是否撐得住。
4. **可行性與備胎**：風險偏高，尚無備案。建議的降級方向是：從四個依變數中選出一到兩個作為核心研究問題（例如先鎖定「學習動機」與「批判思考能力」，因為兩者理論脈絡較常被一起討論），其餘依變數可以保留在文獻回顧或未來研究建議中，不必在同一份論文裡都跑出完整的假說檢定。
5. **具體建議**：
   - 先確定這個研究要補的是哪一種缺口（檢查點 A），這會決定後續理論框架的選擇。
   - 從四個依變數中收斂出 1～2 個核心依變數，其餘降為探索性變項或未來研究方向，處理戰線過長的問題。
   - 把目的句改寫成正式研究問題句（例如「生成式AI使用頻率對大學生學習動機的預測效果為何？」），並確認方向性已寫入。
   - 確認樣本來源與量表選用，评估資料可得性與時程可行性。

- （檢查點 A）「你這個研究要補的是文獻證據不足、完全沒人研究過、方法上的限制，還是理論解釋不完整？」

## 總結
**需重新收斂** — 核心問題是戰線過長：四個依變數分屬不同理論脈絡，目前的敘述比較像是「一個研究方向」而非「一個可執行的研究問題」。建議先決定要不要都做，還是收斂成 1～2 個核心依變數，再往下補齊缺口分類、理論框架與資料可得性。
