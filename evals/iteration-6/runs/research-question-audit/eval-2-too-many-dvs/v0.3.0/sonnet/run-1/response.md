# 研究問題稽核報告

## 稽核對象
「生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：未通過
理由：使用者尚未指名屬於證據／知識／方法／理論／情境缺口中的哪一種。這類主題（生成式AI對學習的影響）目前文獻量已經不少，較可能落在「證據缺口」（不同研究對正／負向效果的結論不一致）或「情境缺口」（特定學科、特定AI工具使用方式下效果不同），但這需要使用者實際盤點文獻後才能指認，不能用「應該有研究價值」帶過。若走情境缺口路線，需補齊「原理論依賴哪條假設」與「被本情境的哪個特性推翻」兩欄，目前兩欄皆缺。

## 檢查點 B：收斂程度
目前所在層次：主題層（尚未收斂到題目層）
建議：已經有明確的自變數（生成式AI）與四個候選依變數，但缺少具體情境（哪個學校／哪個學科／使用哪種生成式AI工具、多長的使用期間）與明確的單一（或最多兩個）依變數。建議先決定「這次研究只回答哪一個核心問題」，再往下收斂。

## 檢查點 C：題目定案六問
1. 一句話講清楚：不通過 — 目前一句話裡塞了四件不同的事（動機、成效、批判思考、就業意願），無法用一句話講清楚「這次研究到底要問什麼」。
2. 有人在乎：不確定 — 教師、教學發展單位、教育政策制定者可能在乎，但使用者尚未具體講出「誰會拿這個答案去做什麼決定」。
3. 缺口分類明確：不通過 — 見檢查點 A。
4. 依變數清楚：不通過 — 四個依變數名稱看得懂，但都沒有操作型定義（例如「學習成效」是指學業成績、自評成效還是測驗分數？「批判思考能力」用什麼工具測？），且數量過多本身就是問題（見檢查點 D）。
5. 資料可得性：不確定 — 尚未說明樣本來源、量表選用或資料蒐集方式。
6. 兩年可行＋降級方案：不通過 — 四個依變數對應到至少四種不同性質的測量工具（動機量表、學業成效指標、批判思考測驗、就業意願量表），工作量與方法複雜度都偏高，且未提出範圍縮小後仍可完成的降級方案。

## 檢查點 D：壞題目長相比對
命中：
- ② 戰線過長 — 依變數達 4 個（學習動機、學習成效、批判思考能力、就業意願），已達成標記門檻，代表題目試圖同時回答太多件事。
- ⑤ 換個名詞就是別人的論文（風險提示，非確定命中）— 「生成式AI對大學生學習動機／學習成效的影響」是目前教育科技領域極熱門的題目，若沒有更具體的情境或理論貢獻，容易與既有研究高度重疊。批判思考能力與就業意願的組合較少見，可能是可以做出差異化的切入點，但需要使用者用文獻回顧證明「目前這個組合／情境確實還沒人做過」。

## 檢查點 E：句型與常見錯誤
句型判定：不適用（使用者目前給的是研究方向描述，尚未寫成正式研究問題句子）
是非問句紅線：不適用（尚未寫成問句）
常見錯誤命中：
- 第 7 條「問題句寫成目的句」— 「我想研究⋯⋯的影響」是目的敘述，之後正式寫研究問題時，需要改寫成「X 對 Y 的預測效果為何」這類可回答的問句，而不是停在目的描述層次。

## 檢查點 F：一致性檢查鏈
目的 → 問題：資訊不足以判斷（使用者只給了研究目的層級的描述，尚未有正式研究問題）

架構 → 分析：資訊不足以判斷（尚未提供）
分析 → 結論：資訊不足以判斷（尚未提供）

## 檢查點 G：對抗式審查
1. **價值審查**：潛在關心者可能是大學教師、教學發展中心、教育政策制定者——他們可能想知道「該不該鼓勵/規範學生用生成式AI」。但這個決定通常是針對「單一具體結果」做的（例如「會不會傷害批判思考」），而不是四個結果一起考慮，所以價值審查會隨依變數收斂而變得更清楚。
2. **理論解構**：這個研究背後隱含一個假設是「生成式AI的使用效果在動機、成效、批判思考、就業意願上方向一致」（例如都正向或都負向）。但這個假設本身很可能不成立——例如「認知卸載」（cognitive offloading）相關文獻指出，AI輔助可能提升短期學習動機與效率，卻同時削弱批判思考的鍛鍊機會，兩者方向可能相反。如果四個依變數的效果方向彼此矛盾，一份研究很難給出一致的結論或建議，這是「戰線過長」在理論層面的具體後果。
3. **方法論審計**：四個依變數分別需要不同性質的測量工具——學習動機通常用量表（如 MSLQ 或 ARCS 相關量表）、學習成效可能用學業成績或自評量表、批判思考能力通常需要專門測驗（如加州批判思考傾向量表）而非自陳量表、就業意願則是另一組態度量表。四種工具的信效度佐證、蒐集方式都不同，若採橫斷面問卷設計，也難以支撐「批判思考能力」這種通常需要較嚴謹測驗設計的構念。
4. **可行性與備胎**：以碩士論文常見的兩年時程，四個依變數＋四種測量工具的組合，資料蒐集與分析工作量偏高。目前沒有提出「如果做不完，先做哪一到兩個依變數」的降級方案。
5. **具體建議**：
   - 先從四個依變數中選出 1（最多 2）個作為核心依變數，其餘可以放進文獻回顧當背景動機，不必全部放進研究架構。
   - 針對選定的依變數，回去查文獻，確認屬於證據缺口還是情境缺口，並補齊對應的兩欄（若走情境缺口路線）。
   - 想清楚「誰會因為這個答案改變什麼決定」，把價值審查的答案具體化。
   - 之後撰寫正式研究問題時，避免寫成「⋯的影響為何」這種目的句，改寫成「X 對 Y 的預測效果為何」這類可回答的問句。
