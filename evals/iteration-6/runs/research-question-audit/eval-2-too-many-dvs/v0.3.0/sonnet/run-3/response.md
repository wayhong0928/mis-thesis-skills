# 研究問題稽核報告

## 稽核對象
「我想研究生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：**未通過**
理由：使用者尚未指名這個研究對應五種缺口（證據／知識／方法／理論／情境）的哪一種。目前的敘述只是「我想看 AI 對這幾個結果的影響」，沒有講出現有文獻在這個關係上是「結果矛盾」（證據缺口）、「完全沒人研究過」（知識缺口）、「方法有限制」（方法缺口）、「理論解釋不足」（理論缺口），還是「情境假設被推翻」（情境缺口）。生成式AI對學習的影響是近兩年高度熱門的題目，若最終選擇情境缺口（例如「還沒人在台灣大學生做過」），會直接命中紅線判定，須補齊「原理論依賴哪一條假設」與「被本情境的哪個特性推翻」兩欄。

## 檢查點 B：收斂程度
目前所在層次：**介於主題層與題目層之間**
建議：自變數（生成式AI的使用）已經具體，但因為同時掛了四個依變數，整體還停在「主題範圍」而非收斂完成的單一題目。建議先決定「主要依變數只留一個」，其餘視為未來延伸或控制變數，才算真正收斂到題目層。

## 檢查點 C：題目定案六問
1. 一句話講清楚：通過 — 目前這句話可以完整表達，但因涵蓋四個結果，讀者需要拆成四句才能個別理解每組關係，屬於邊界通過。
2. 有人在乎：不確定 — 大學教師、教務單位、政策制定者可能都在乎，但使用者未講出「拿到答案後，這些人具體會用它做什麼決定」。
3. 缺口分類明確：不通過 — 同檢查點 A。
4. 依變數清楚：通過 — 學習動機、學習成效、批判思考能力、就業意願都是文獻中常見且可操作化的構念，個別而言都講得清楚（但依變數數量過多的問題見檢查點 D-②）。
5. 資料可得性：不確定 — 未說明抽樣對象（哪些學校／科系的大學生）、樣本規模、預計使用的量表來源。
6. 兩年可行＋降級方案：不通過 — 四個依變數若都要建立完整測量與分析（可能還需中介/調節機制），對碩士論文兩年期程而言負荷偏重，且未見任何降級方案。

## 檢查點 D：壞題目長相比對
命中：
- **② 戰線過長** — 依變數達 4 個（學習動機、學習成效、批判思考能力、就業意願），已達到「同時回答三四件事」的門檻，應收斂或拆分。
- **③ 變數沒有理論來源（風險，待確認）** — 四個依變數各自在文獻中都有對應理論基礎（如自我決定理論之於學習動機、社會認知生涯理論之於就業意願），但使用者目前未交代要用哪個理論框架把「生成式AI使用」與這四者串起來，需要補充後才能判定是否通過。
- **⑤ 換個名詞就是別人的論文（風險，待確認）** — 「生成式AI對學習動機/成效的影響」是目前教育科技領域極熱門的題目，架構若照搬既有 TAM／UTAUT 研究換個依變數，容易被質疑新意不足，需要在檢查點 A 補齊具體缺口後才能排除此風險。

## 檢查點 E：句型與常見錯誤
句型判定：不適用 — 目前是研究興趣的口語敘述，尚未寫成正式研究問題句。
是非問句紅線：不適用（同上）。
常見錯誤命中：
- **#7 問題句寫成目的句** — 「我想研究……的影響」是目的描述，還沒有轉換成可被回答的問句形式（例如「生成式AI使用頻率對大學生學習動機的預測效果為何？」）。
- **#2 一題塞進多條因果路徑** — 一句話同時包含四條「生成式AI → 依變數」的因果路徑。

## 檢查點 F：一致性檢查鏈
使用者僅提供「目的」層級的敘述，尚未有正式研究問題、假說、研究架構或分析方法，以下各環資訊不足以判斷：
- 問題 → 假說：不足
- 假說 → 架構：不足
- 架構 → 分析：不足
- 分析 → 結論：不足

## 檢查點 G：對抗式審查
1. **價值審查**：可能在乎的對象包括大學教學發展中心、通識/課程設計者、教育政策制定者。但目前講不出「他們拿到答案後會做什麼具體決定」——是要決定要不要開放AI輔助作業？調整課程設計？還是評估學生未來競爭力？需要指定一個具體的決策情境。
2. **理論解構**：隱含假設是「生成式AI使用會正向影響這四個結果」，但這個假設本身有爭議——例如認知卸載（cognitive offloading）文獻指出，過度依賴AI可能反而削弱批判思考能力，與學習動機的正向假設方向相反。如果依變數之間的預期效果方向不一致，這個研究問題內部可能存在矛盾，需要先想清楚。
3. **方法論審計**：尚未說明採量化（問卷）、質性（訪談）或混合方法；四個依變數若都採量表測量，需分別確認每個構念是否有現成信效度佐證的量表，樣本規模是否足以支撐同時檢驗四組關係（尤其若想用SEM等方法，經驗法則門檻會隨依變數增加而提高）。抽樣方法（便利抽樣／機率抽樣）與代表性宣稱範圍也尚未交代。
4. **可行性與備胎**：四個依變數＋可能的中介/調節機制，對兩年期程的碩士論文而言風險偏高。降級方案可以是：先聚焦「生成式AI對學習動機」單一主軸完成核心研究，其餘三者作為文獻回顧中的延伸討論或未來研究建議；或選一個依變數為主、一個為次要依變數，其餘兩個捨棄。
5. **具體建議**：（1）先做文獻回顧，確認這個題目在證據／知識／方法／理論／情境缺口中屬於哪一種，並避免僅以「還沒人在台灣大學生做過」作為情境缺口理由；（2）從四個依變數中選出 1（最多 2）個作為正式研究的依變數；（3）決定串連自變數與依變數的理論框架（例如 UTAUT＋認知負荷理論，或自我決定理論），並想清楚理論解構步驟提到的「AI可能有負面效應」是否要納入研究問題；（4）確認樣本來源與可用量表後，再回頭補齊檢查點 C 的六問。
