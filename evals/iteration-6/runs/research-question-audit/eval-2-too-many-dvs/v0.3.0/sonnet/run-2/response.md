# 研究問題稽核報告

## 稽核對象
「生成式AI對大學生學習動機的影響，同時也想看它對學習成效、批判思考能力、還有未來就業意願的影響」

## 檢查點 A：研究缺口分類
判定：**未通過**
理由：使用者尚未指明屬於證據／知識／方法／理論／情境缺口中的哪一種。目前的敘述只是描述一個「想觀察的現象」，沒有講出「文獻現在卡在哪裡、你的研究要補上什麼」。這件事必須先想清楚，因為它會決定後面依變數要怎麼收斂。

## 檢查點 B：收斂程度
目前所在層次：**介於子題與題目層之間**
建議：「生成式AI對大學生學習」這個範圍已經算是子題，但因為一次掛了四個依變數，還沒收斂成一個可以獨立成立的「題目」。收斂方向是先決定這四個依變數裡，哪一個（或哪兩個，若有明確的因果先後關係）才是真正要回答的核心問題。

## 檢查點 C：題目定案六問
1. 一句話講清楚：**不通過** — 句子本身讀得出來，但裡面塞了四個依變數，讀者無法判斷你真正要回答的是哪一個問題。
2. 有人在乎：**通過** — 大學教師、課程設計者、教育政策制定者會關心生成式AI對學習的影響，這個大方向有人在乎。
3. 缺口分類明確：**不通過** — 呼應檢查點 A。
4. 依變數清楚：**不通過** — 「學習成效」「批判思考能力」「未來就業意願」各自要對應到什麼構念、怎麼操作化測量，目前都沒有講清楚。
5. 資料可得性：**不確定** — 未提供樣本來源、預計樣本數、擬使用量表，無法判斷。
6. 兩年可行＋降級方案：**不通過** — 四個依變數各自都要有信效度佐證的量表，若還打算檢驗變數間的路徑關係，樣本量與分析複雜度會明顯提高，且未見降級方案。

## 檢查點 D：壞題目長相比對
命中：
- **②戰線過長**：依變數達 4 個（學習動機、學習成效、批判思考能力、未來就業意願），遠超過建議的 1–2 個上限，是這個研究想法目前最明顯的結構性問題。
- **③變數沒有理論來源（不確定）**：四個變數各自可能有對應理論（如動機的 ARCS 模型或自我決定理論、批判思考的 Ennis 架構），但使用者尚未交代，暫列不確定，需要補齊。
- **⑤換個名詞就是別人的論文（不確定）**：「生成式AI對大學生學習動機／成效的影響」是近兩年非常熱門的題型，目前的敘述看不出跟既有研究的具體差異點在哪裡，需要使用者說明。

未命中：①、④、⑥。

是非問句紅線：**不適用**（目前問題連「是否」都還沒寫出來，屬於更前一步的問題——寫成目的句而非問句）。

## 檢查點 F：一致性檢查鏈
目的 → 問題：資訊不足以判斷（研究目的與研究問題目前混在一起，且問題本身還沒收斂完成）。
問題 → 假說：資訊不足以判斷（尚未提供假說）。

## 檢查點 G：對抗式審查
1. **價值審查**：大學教師、課程設計者、教育政策制定者會關心生成式AI對學習的影響，但因為依變數太多，「拿到答案之後能做什麼決定」目前並不清楚——如果四個結果有的顯著、有的不顯著，教學政策該怎麼調整？收斂到一兩個核心依變數後，這個問題才會有明確答案。
2. **理論解構**：目前的架構隱含一個假設——「生成式AI使用」是外生自變數，直接影響四個平行的結果變數。但這四個變數彼此很可能不是平行關係，例如批判思考能力可能是學習成效的前置因子，學習動機也可能中介AI使用與學習成效之間的關係。如果不先釐清變數間的因果順序，模型設定本身就可能站不住腳。
3. **方法論審計**：目前設計偏向量化問卷調查。每個依變數都需要信效度已驗證的量表（例如學習動機可能用 MSLQ、批判思考傾向可能用 CCTDI），使用者尚未交代擬用哪些量表及其信效度來源。若採橫斷面設計，無法確立「使用AI → 動機提升」的因果順序，只能講相關。抽樣方式（機率／便利抽樣）與樣本代表性也尚未說明。
4. **可行性與備胎**：四個依變數 × 各自的量表與信效度檢驗，若還想檢驗變數間路徑（如中介模型），樣本量需求會明顯提高，兩年內完成風險偏高。目前沒有看到降級方案。
5. **具體建議**：
   - 先決定四個依變數裡哪一個是核心（或哪兩個有明確理論先後關係），其餘可以降級為未來研究方向或探索性附加分析。
   - 明確指名研究缺口類型（證據／知識／方法／理論／情境之一）。
   - 為保留下來的依變數找到已驗證量表，或說明改編依據。
   - 把研究問題從目的句改寫成量化句型（例如：「生成式AI使用頻率對大學生學習動機的預測效果為何？」）。
   - 補齊抽樣計畫（母體、樣本數、抽樣方法）與資料可得性說明。
