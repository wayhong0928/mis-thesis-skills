## 主要問題：結果section 混入了討論內容

以下三句其實是「討論／限制」的內容，不應該放在結果章：
- 「這兩項結果與 Venkatesh 等人（2012）在消費者情境的發現方向一致」→ 這是文獻比較與詮釋
- 「然而...無法排除反向解釋...」→ 這是限制的討論
- 「後續研究可採縱貫設計確認時間先後」→ 這是未來研究建議

結果章應該只客觀報告數據，不做詮釋、不比較文獻、不談限制。建議把這三句移到討論／限制章節，結果章只保留到「皆具有顯著正向影響」為止。

## 統計報告不完整

PLS-SEM 的結果報告通常還需要：

1. **R²（決定係數）**：持續使用意圖被知覺有用性與知覺易用性解釋的變異量是多少？例如「模型解釋持續使用意圖 XX% 的變異量（R² = .xx）」。這是 PLS-SEM 結果章的核心資訊之一，目前完全沒有。

2. **效果量 f²**：β 值本身不代表效果大小，建議補充 Cohen's f² 並說明是小/中/大效果。

3. **顯著性檢定方法**：PLS-SEM 通常用 bootstrapping（如 5000 次重複抽樣）取得 t 值與 p 值，建議註明「以 5,000 次拔靴法（bootstrapping）檢定路徑係數顯著性」，並可補上 t 值或 95% 信賴區間，比單獨報 p 值更符合目前 PLS-SEM 報告規範。

4. **控制變項的效果本身未報告**：只說「控制性別與年級後」，但這兩個控制變項對依變項是否有顯著效果，讀者也會想知道，建議一併報告（或至少註明「性別與年級對持續使用意圖無顯著影響」）。

5. **測量模型資訊**：若前面章節尚未報告信效度（如 AVE、CR、區別效度），這裡至少要有一句銜接，例如「測量模型信效度符合標準後，結構模型分析顯示...」，讓結果章邏輯完整。
