## 學術寫作品質稽核結果

（誠實條款：本次稽核未核對 Davis, 1989 及 Bastani et al., 2024 原文，兩處轉述是否忠於原意需使用者自行核對。）

### 致命（因果動詞越線 / 自創構念）

- 原句：「知覺易用性則導致學生的持續使用意圖顯著提升（β = .22, p < .01）。」
  問題：兩處理由重疊——① 「導致」是門檻最高的因果動詞，即使三條件（理論依據＋路徑分析＋控制變數）都滿足，替換表建議最多退回「影響」，不建議直接用「導致」；② 緊接在前一句「知覺有用性對持續使用意圖**具有顯著正向影響**」之後，同一模型、同一類型的路徑係數卻換了因果強度更高的動詞，這種同段落內動詞紀律不一致，是口試委員最容易切入質疑的地方。
  改法：「知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。」

- 原句：「此結果支持本研究提出的『認知卸載侵蝕路徑』，亦即學生把思考外包給AI之後，自主除錯能力隨之流失。」
  問題：兩處理由——① 把一個迴歸關聯包裝成「⟨某某⟩侵蝕路徑」這類看似既有構念的自創名詞，正是判準範例中明確列出的紅線；② 「知覺有用性→依賴程度」仍是同一時間點蒐集的橫斷面資料，卻用「之後……隨之流失」寫出具時間先後的能力衰退機制，超出這筆資料能支持的因果強度（沒有縱貫或實驗設計可以確認先後次序，也無法排除其他解釋）。
  改法：「此結果顯示，知覺有用性愈高的學生，依賴程度也愈高，但受限於橫斷面設計，本研究無法確認兩者的時間先後、亦無法排除其他解釋，因此不宜逕自推論為自主除錯能力的流失。」

### 錯誤（用語 / APA 格式）

- 原句：「研究者通過網路問卷收集數據」
  問題：「通過」「收集數據」為大陸用語，台灣學術慣用「透過」「蒐集資料」。
  改法：「研究者透過網路問卷蒐集資料」

- 原句：「發現感知有用性愈高的學生，依賴程度也愈高」
  問題：全篇前兩處都寫「知覺有用性」，此處突然換成「感知有用性」，同一構念交替使用兩個譯名。
  改法：統一為「知覺有用性」。

- 原句：「Bastani et al.（2024）以隨機分派實驗發現……」
  問題：英文三位以上作者的敘述引用，台灣 APA 7 中文化慣例應寫「等人」，中文行文不用「et al.」。
  改法：「Bastani 等人（2024）以隨機分派實驗發現……」

### 通過項目

- 「依賴程度與持續使用意圖亦呈顯著正相關（r = .38, p < .001）」正確使用相關語言，未越線寫成因果。
- 引用 Bastani et al.（2024）的隨機分派實驗時使用「導致」，符合「例外一：引用具可信因果識別策略的研究」的判準，這處因果動詞本身沒有問題（僅需修 et al. 格式）。
- APA 內文引用「Davis（1989）」格式正確。

### 整合修改版

本研究以科技接受模型為理論基礎，採橫斷面問卷調查，探討大學生持續使用生成式AI輔助程式設計的意圖。研究者透過網路問卷蒐集資料，共回收有效問卷 312 份，所有題項皆以 Likert 七點量表測量。資料以 SmartPLS 4 分析，並將性別與年級納入控制變數。

分析結果顯示，在控制性別與年級後，知覺有用性對持續使用意圖具有顯著正向影響（β = .41, p < .001），此結果與 Davis（1989）的主張一致。知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。另外，依賴程度與持續使用意圖亦呈顯著正相關（r = .38, p < .001）。

本研究進一步以多元迴歸分析檢驗依賴程度的前因，發現知覺有用性正向預測依賴程度。此結果顯示，知覺有用性愈高的學生，依賴程度也愈高，但受限於橫斷面設計，本研究無法確認兩者的時間先後、亦無法排除其他解釋，因此不宜逕自推論為自主除錯能力的流失。Bastani 等人（2024）以隨機分派實驗發現，練習期間使用未加限制的 GPT-4 導致學生在後續閉卷測驗的表現下降；此發現雖來自不同的研究設計與樣本，仍提醒教師在課程設計上應考量生成式AI對學習可能造成的衝擊，未來研究可透過縱貫設計或實驗法進一步檢驗本研究觀察到的依賴關聯是否具有因果性質。

### 一句話總結

需修（致命 2 處、錯誤 3 處、瑕疵 0 處）。核心問題是「認知卸載侵蝕路徑」這個自創構念名稱把橫斷面相關包裝成有時序性的因果機制，加上「導致」與前句「影響」在同一分析類型下不一致，這兩點是口試最容易被追問的地方，建議優先處理。
