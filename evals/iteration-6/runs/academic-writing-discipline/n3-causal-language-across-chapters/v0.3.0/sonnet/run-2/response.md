## 學術寫作品質稽核結果

### 致命（因果動詞越線）

- 原句：「本研究發現科技焦慮**導致**學生更頻繁地向生成式AI求助」
  問題：第四章的統計結果只到「顯著正向影響」（β = .29），第五章卻升級成「導致」。即便本研究同時符合三條件（理論支持、PLS-SEM 路徑分析、控制變數），「導致」暗示排除其他解釋的確定性因果，門檻高於「影響」，橫斷面資料無法排除倒果為因（例如原本就常求助AI的學生,可能因此更常意識到自己的科技焦慮）。全篇因果動詞紀律也因此前後不一致：第四章用「影響」，第五章用「導致」。
  改法：「本研究發現科技焦慮對學生的生成式AI求助行為具有顯著正向影響」

- 原句：「顯示焦慮是學生轉向AI的**主要原因**」
  問題：「主要原因」是比其他可能原因更強的絕對因果宣稱，超出單一橫斷面路徑係數能佐證的範圍——β = .29 只能說明科技焦慮是顯著的預測因子之一,無法排除或比較其他未納入模型的原因(例如作業壓力、同儕使用習慣)的相對重要性。
  改法：「顯示科技焦慮是學生求助生成式AI行為的重要預測因子之一」

### 通過項目

- 第一章「大學生的科技焦慮對其生成式AI求助行為的**影響**為何？」：用「影響」提問本身沒問題，且後續第四章確實以理論（壓力因應理論）+ PLS-SEM 路徑分析 + 控制變數三條件支持，屬於可正當使用「影響」的情境。
- 第四章「科技焦慮對生成式AI求助行為具有顯著正向**影響**（β = .29, p < .001）」：三條件（理論依據、路徑分析、控制變數）皆已交代，用「影響」搭配β值是安全寫法，不需要退回「預測」。

### 整合修改版

【第五章 討論（修正版）】
本研究發現科技焦慮對學生的生成式AI求助行為具有顯著正向影響，顯示科技焦慮是學生求助生成式AI行為的重要預測因子之一。

需修（致命 2 處：「導致」越線、「主要原因」誇大因果強度；第一、四章因果動詞用法皆通過)。
