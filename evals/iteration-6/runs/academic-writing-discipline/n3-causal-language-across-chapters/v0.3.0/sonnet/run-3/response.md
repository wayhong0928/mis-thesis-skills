## 學術寫作品質稽核結果

### 致命（因果動詞越線 / 前後不一致）

- **原句（第五章）**：「本研究發現科技焦慮**導致**學生更頻繁地向生成式AI求助，顯示焦慮是學生轉向AI的**主要原因**。」
  **問題**：本研究是橫斷面問卷調查，即便有理論建模、PLS-SEM 路徑分析與控制變數三條件加持，這三個條件依 SKILL 判準頂多能支持「影響」這個詞，**不足以支持「導致」與「主要原因」這種排除其他解釋的絕對因果語言**。橫斷面自陳資料無法排除：(1) 反向因果（求助頻率高的學生可能因AI表現不如預期而產生更多焦慮）、(2) 共同方法變異（同一份問卷同時測焦慮與求助行為，關聯可能被膨脹）、(3) 未納入的第三變數。此外，「主要原因」隱含比較其他可能原因後的排除性判斷，但本研究並未檢驗其他候選原因（如自我效能、社會影響等），這個詞已超出資料能支持的強度。
  **問題（前後不一致）**：第一章研究問題與第四章結果都用「影響」，第五章卻跳到「導致」「主要原因」，同一份論文內因果語言強度前後不一致，會讓口試委員質疑討論章是否誇大了結果。
  **改法**：「本研究發現科技焦慮對學生的生成式AI求助行為具有正向影響，此結果與壓力因應理論的預期一致，意味著焦慮程度較高的學生傾向更頻繁地向生成式AI求助。惟因本研究為橫斷面設計，尚無法排除反向因果或其他未納入變數的可能性，此關聯是否具有因果方向仍待縱貫或實驗設計進一步檢驗。」

### 通過項目

- **第一章**「科技焦慮對其生成式AI求助行為的**影響**」：研究問題階段用「影響」是常見且可接受的寫法，未越線。
- **第四章**「科技焦慮對生成式AI求助行為具有顯著正向**影響**（β = .29, p < .001）」：已具備理論建模＋PLS-SEM（路徑分析性質）＋控制變數三條件，此時使用「影響」是可接受的寫法，因果動詞紀律上沒有問題。

---

### 整合修改版（第五章討論段落）

> 本研究發現科技焦慮對學生的生成式AI求助行為具有正向影響，此結果與壓力因應理論的預期一致：焦慮程度較高的學生傾向更頻繁地向生成式AI求助，可能將求助AI視為降低不確定感的因應策略之一。惟本研究採橫斷面設計，資料無法排除反向因果（求助後的AI使用經驗回頭影響焦慮）或共同方法變異等替代解釋，焦慮與求助行為之間是否具有因果關係，仍有待未來以縱貫設計或實驗操弄進一步檢驗。

### 一句話總結

需修（致命 1 處）——第五章「導致」「主要原因」需降級為「影響」並補上因果限制的 hedging，第一、四章因果用詞本身沒有問題。
