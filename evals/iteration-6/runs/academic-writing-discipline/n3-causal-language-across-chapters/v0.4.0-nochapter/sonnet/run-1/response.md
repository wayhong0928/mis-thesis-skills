## 學術寫作品質稽核結果（因果用詞為主）

### 致命（因果動詞越線 / 全篇紀律不一致）

- 原句：「本研究發現科技焦慮**導致**學生更頻繁地向生成式AI求助，**顯示焦慮是學生轉向AI的主要原因**。」（第五章）
  問題有兩層：
  1. 這是橫斷面問卷資料的路徑係數，「導致」是排除其他解釋的絕對因果動詞，門檻遠高於第四章已用的「影響」。即使第四章因為滿足三條件（理論依據、PLS-SEM 路徑分析、控制變數）而能合格使用「具有顯著正向影響」，討論章不能再往上加碼升級為「導致」——這正是「全篇動詞紀律要一致，比用哪個詞本身更重要」的典型違例：結果章保守，討論章卻突然變強。
  2. 「顯示焦慮是**主要原因**」是更嚴重的排他性因果宣稱：一個 β = .29 的路徑係數並未排除其他未測變數（例如自我效能、任務難度）的貢獻，也沒有跟其他原因做相對比較，無法支持「主要原因」這個結論。
  改法：「本研究結果顯示，科技焦慮對學生的生成式AI求助行為具有顯著正向影響，此發現與……（理論依據）之預期一致。」——去掉「導致」與「主要原因」，動詞強度收斂回第四章已建立的「影響」，不再往上加碼。

### 通過項目

- **第一章（研究問題）**：「大學生的科技焦慮對其生成式AI求助行為的影響為何？」——研究問題階段用「影響」是在陳述要探究的關係，不是主張既成因果結論，屬於常見且可接受的寫法。
- **第四章（結果）**：同時滿足三條件——依據壓力因應理論建立模型（理論支持）、以 PLS-SEM 路徑分析（迴歸／路徑分析）、控制性別、年級、程式設計經驗（控制變數介入）。此時「具有顯著正向影響」是合格、專業的寫法，不需要退回「預測」。
- 用語、標點、引用格式：三段皆未見大陸用語（資料、蒐集、迴歸等用法皆正確）、標點與統計呈現方式（β、p 值）也符合台灣學術慣例。

### 整合修改版

【第一章 研究問題】（不需修改）
本研究欲回答：大學生的科技焦慮對其生成式AI求助行為的影響為何？

【第四章 結果】（不需修改）
本研究為橫斷面問卷調查（N = 298）。依據壓力因應理論建立模型，以 PLS-SEM 分析並控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向影響（β = .29, p < .001）。

【第五章 討論】（修改）
本研究結果顯示，科技焦慮對生成式AI求助行為具有顯著正向影響，此發現與壓力因應理論的預期一致，即個體面對科技相關壓力源時，可能傾向採取求助行為作為因應策略。惟本研究為橫斷面設計，無法排除求助行為與科技焦慮之間可能存在的其他解釋路徑，相關推論仍待未來縱貫或實驗設計進一步檢驗。
