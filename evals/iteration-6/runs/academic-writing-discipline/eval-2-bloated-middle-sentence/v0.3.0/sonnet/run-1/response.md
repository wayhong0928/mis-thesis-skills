會有,而且滿典型的——你的句子完全對到規則裡明講的高風險句型:「由於……因此」,中間夾的成分超過 15 字的門檻很多(超過 60 字)。

**問題所在**

```
由於[原因:近年來生成式AI技術的快速發展與普及]，
使得[中介效果:越來越多的大學生...產生了高度的依賴性]，
因此[主要動詞才出現:本研究希望...探討...影響]
```

真正的主語「本研究」要等到句子最後三分之一才出現,前面塞了兩層因果(先是AI技術發展→大學生依賴,再由這個依賴接到研究動機),讀者要撐到句尾才抓得到這句話到底在講誰、要做什麼。

這同時也牽動到另一條規則——**一句一話題**:這句話裡話題其實換了三次(AI技術 → 大學生 → 本研究),但用逗號硬串成一句,沒有隨話題轉移斷句。

**改法**(依規則:「由於 A,因此 B」若 A 很長,先把因果說完斷句,再帶出研究動機)

> 近年來生成式AI技術快速發展與普及,越來越多大學生在課業與報告撰寫過程中,對這類工具產生了高度依賴。基於此,本研究希望探討這種依賴傾向對學生學習成效的影響。

拆成兩句後,每句話題明確(第一句講學生現象、第二句講研究動機),「由於……因此」的橋接詞也不需要硬撐一整句。
