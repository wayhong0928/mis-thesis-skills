- 原句：「Fornell **&** Larcker（1981）」
  問題：APA 7 中文化格式中，英文作者之間應使用中文「與」，不用「&」。
  改法：「Fornell 與 Larcker（1981）」

- 原句：「收斂效度與**判別效度**」
  問題：「判別效度」是大陸用語（discriminant validity），台灣慣用「區辨效度」或「區別效度」。

  改法：「Venkatesh 等人（2012）」
