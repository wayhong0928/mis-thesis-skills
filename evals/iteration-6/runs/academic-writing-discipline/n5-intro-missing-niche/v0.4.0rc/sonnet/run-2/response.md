# 學術寫作品質稽核結果

這是緒論第一節草稿，已套用 CARS model（緒論三功能）與一般構句／用語判準。

### 錯誤（結構 / APA 格式）

- **問題：Move ②（研究缺口）缺失。**
  第一段完整陳述了「生成式AI很普及、政策也重視」（Move ①），但緊接著「因此，本研究的目的在於……」直接跳到 Move ③，中間沒有交代「既有研究到哪裡就停了」。讀者看不出：政策重視 ≠ 需要做這篇研究，兩者之間缺一個橋樑——例如「依賴程度是否已被量化」「科技焦慮與自我效能這兩個變項是否已被檢驗過」。
  這是口試委員最容易切入的一點：委員只要問「所以呢？為什麼需要研究這個？」，目前的段落答不出來。
  改法：在「顯示這個議題受到政策層面的重視」之後、「因此」之前，插入一段點出缺口，例如：「然而，目前對於大學生在程式設計課程中『依賴』生成式AI的程度，以及哪些心理因素會加深或降低這種依賴，實證研究仍相對有限；科技焦慮與自我效能是否能預測依賴程度，尤其缺乏系統性的檢驗。」

- **原句：「教育部也在 2023 年發布大專校院使用生成式AI的參考指引（教育部，2023），顯示……」**
  問題：句中已用敘述方式帶出「教育部」與「2023 年」，後面又重複加上括號引用「（教育部，2023）」，等於同一筆文獻標示了兩次年份，不符合 APA 7 中文化的敘述引用格式（應是「教育部（2023）指出／發布……」，年份放在作者名後的括號內，不需另外重複）。
  改法：「教育部（2023）也已發布大專校院使用生成式AI的參考指引，顯示這個議題受到政策層面的重視。」

### 瑕疵（構句可再優化，是否要修由你判斷）

- **原句：「許多大學生已使用 ChatGPT 等工具完成課業，程式設計課程尤其常見。」**
  問題：話題從「大學生」漂移到「程式設計課程」，「程式設計課程尤其常見」缺主詞承接，讀者要自己補回「這個現象在程式設計課程中尤其常見」才能讀通。
  改法：斷句，「許多大學生已使用 ChatGPT 等工具完成課業。這樣的現象在程式設計課程中尤其常見。」

- **問題：「生成式AI能即時產生程式碼、解釋錯誤訊息，已成為許多學生學習程式設計時的日常工具」這句是經驗性斷言（描述學生實際使用行為），但全段只有一筆引用（教育部，2023），且那筆引用支持的是「政策重視」而非「已成為日常工具」這件事。**
  這不是格式錯誤，但口試時容易被問「這句話的根據是什麼」。若手上有相關文獻（例如學生使用行為調查），建議在此處補引用；若沒有，也可以把語氣稍微收斂為「可能已成為……」或改寫成你自己觀察到的現象陳述。

### 通過項目

- 因果動詞紀律：全段未見「導致」「造成」等越線動詞；研究目的用「預測效果」，與 PLS-SEM 橫斷面問卷設計的證據強度相符，用詞恰當。
- 標點與數字格式：全形標點、阿拉伯數字＋中文量詞（「2023 年」）皆正確。
- 用語：未發現大陸用語（資料、蒐集、迴歸等用法皆正確）。

### 整合修改版

『近年來，生成式AI工具快速普及，許多大學生已使用 ChatGPT 等工具完成課業。這樣的現象在程式設計課程中尤其常見：生成式AI能即時產生程式碼、解釋錯誤訊息，已成為許多學生學習程式設計時的日常工具。教育部（2023）也已發布大專校院使用生成式AI的參考指引，顯示這個議題受到政策層面的重視。

然而，目前對於大學生在程式設計課程中「依賴」生成式AI的程度，以及哪些心理因素會加深或降低這種依賴，實證研究仍相對有限；科技焦慮與自我效能是否能預測依賴程度，尤其缺乏系統性的檢驗。

因此，本研究的目的在於探討大學生在程式設計課程中對生成式AI的依賴程度，以及科技焦慮與自我效能對依賴程度的預測效果。本研究以問卷調查蒐集資料，並以 PLS-SEM 進行分析。本論文共分五章：第二章為文獻探討，第三章說明研究方法，第四章呈現分析結果，第五章為結論與建議。』

（研究缺口段落中「實證研究仍相對有限」這句是佔位描述，正式定稿前請換成你實際文獻回顧中找到的具體缺口，並補上支持的引用。）
