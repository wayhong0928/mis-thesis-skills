# 學術寫作品質稽核結果

**誠實條款**：本次稽核未核對「教育部（2023）」原文內容，轉述是否偏離原意需你自行核對。

### 致命
無。全篇未見因果動詞越線——「預測效果」一詞用得恰當，符合橫斷面問卷資料應有的保守語氣。

### 錯誤（結構 / APA 格式）

**1. 緒論缺了「建立利基」（move ②），只有 move ①③**
第一段講完生成式AI多重要、教育部多重視（move ①），第二段直接跳到「因此，本研究的目的在於……」（move ③），中間完全沒有交代「既有研究做到哪裡、留下什麼缺口」。讀者看不出「為什麼非做這個題目不可」——這是稽核緒論時最容易漏、也最值錢的一步。
**改法**：在兩段之間加一段，明確指出既有文獻已經涵蓋什麼（例如生成式AI對學習成效的影響）、還沒回答什麼（例如依賴程度本身、科技焦慮與自我效能在其中的角色），再接「因此，本研究的目的在於……」。這段內容要跟你文獻探討章實際涵蓋的文獻對得起來，不能空泛寫「研究較少」卻未驗證。

**2. 引用格式重複**
原句：「教育部也在 2023 年發布大專校院使用生成式AI的參考指引（教育部，2023），顯示這個議題受到政策層面的重視。」
問題：句中已用敘述方式交代「教育部」與「2023 年」，句尾又加上括號（教育部，2023），造成年份重複標註。
改法：「教育部（2023）發布大專校院使用生成式AI的參考指引，顯示政策層面同樣重視這項議題。」

### 瑕疵（是否修改由你決定）

- **第一句話題漂移**：「近年來，生成式AI工具快速普及，許多大學生已使用 ChatGPT 等工具完成課業，程式設計課程尤其常見。」一句內話題從「AI工具」漂到「大學生」再漂到「程式設計課程」，且最後一個分句缺主詞，讀者需自行腦補成「在程式設計課程中尤其常見」。可考慮斷句或補上主詞。
- **模糊量詞缺佐證**：「許多大學生已使用 ChatGPT」的「許多」沒有具體數字或引用支持，讀起來偏空泛。若手上有調查數據或文獻可引，補上會更有說服力。
- **「受到政策層面的重視」**：被動＋弱動詞組合，緒論慣例建議改回主動，例如「政策層面也重視這項議題」。
- **研究目的句偏長**：「本研究的目的在於探討……依賴程度，以及……預測效果。」把兩個子目的塞進一句，可考慮拆成兩句分別陳述，閱讀負擔會更小。

### 通過項目
- 因果動詞紀律：全篇未見「導致」「影響」等越線用詞，「預測效果」用法與橫斷面問卷設計相符。
- 台灣學術用語：未見大陸用語混用。
- 標點與人稱：全形標點一致，未見不當破折號或引號混用。

### 整合修改版

> 近年來，生成式AI工具快速普及。許多大學生已使用 ChatGPT 等工具完成課業，在程式設計課程中尤其常見［建議補上具體統計或引用文獻，佐證「許多」的說法］。生成式AI能即時產生程式碼、解釋錯誤訊息，已成為許多學生學習程式設計時的日常工具。教育部（2023）也發布大專校院使用生成式AI的參考指引，顯示政策層面同樣重視這項議題。
>
> 然而，現有研究多聚焦於⟨依你文獻探討實際內容補：例如生成式AI對學習成效或學業表現的影響⟩，較少探討⟨依你文獻探討實際內容補：例如學生對生成式AI的依賴程度本身，以及科技焦慮、自我效能等個人特質在其中的角色⟩。
>
> 因此，本研究的目的在於探討大學生在程式設計課程中對生成式AI的依賴程度，並檢驗科技焦慮與自我效能對此依賴程度的預測效果。本研究以問卷調查蒐集資料，並以 PLS-SEM 分析資料。本論文共分五章：第二章為文獻探討，第三章說明研究方法，第四章呈現分析結果，第五章為結論與建議。
