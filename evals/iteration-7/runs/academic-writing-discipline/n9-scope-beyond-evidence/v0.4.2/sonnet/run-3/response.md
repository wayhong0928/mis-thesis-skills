## 學術寫作品質稽核結果

這段結論的問題不在用字，而在主張比證據大很多。致命級有 3 處。

### 致命（主張強度超出證據）

- **原句**：「受試者在生成式AI依賴量表的平均分數為 4.9……臺灣大學生普遍已對生成式AI成癮」
  - **問題**：量表測的是「依賴」，結論卻寫成「成癮」。這是構念替換。成癮通常需要診斷準則或臨界分數，平均 4.9 只說明樣本在依賴量表上偏高。七點量表的中點是 4，4.9 也只比中點高一些，而且沒有報告標準差，也沒有和中點做檢定。
  - **改法**：前後都用「依賴」。補上標準差與對中點的檢定，再寫「依賴程度偏高」。

- **原句**：「臺灣大學生普遍已……」
  - **問題**：樣本是單一學校、單一科系的 182 人，而且是資管系學生，本來就可能比一般學生更常用生成式AI。這個樣本推不到全臺灣大學生。
  - **改法**：把結論範圍縮回「本研究樣本」，並在限制中說明抽樣來源。

- **原句**：「由此可知……教育主管機關應儘速介入。」
  - **問題**：「由此可知」把一個描述性平均數當成確定結論。「應儘速介入」是政策主張，但前面沒有任何資料顯示有危害，也沒有顯示介入有效。橫斷面的平均分數撐不起這一步。
  - **改法**：刪掉政策呼籲，改成對後續研究的建議。

### 瑕疵（是否修改由你決定）

  - **問題**：中英文之間有沒有空格，與同段的「182 名」不一致。
  - **改法**：全篇統一。
