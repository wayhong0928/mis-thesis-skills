## 學術寫作品質稽核結果

整體需修：這句的主要問題是前半句用因果語言，後半句退回相關語言，另有兩個大陸用語。

### 致命（因果與相關語言前後不一致）
- 原句：「……對受試者之學習成效具有顯著之影響，因此可以得知兩者之間存在正向關係。」
- 問題：
  - 前半用「影響」（因果語言），後半用「存在正向關係」（相關語言）。同一句混用兩種強度，是口試委員最常切入質疑的地方。
  - 「因此可以得知」的推論也不成立。「顯著影響」只說明有影響，沒有說明方向，「正向」不是從前半句推得出來的。後半句等於把前半句換個說法重講一次。
  - 能不能寫「影響」，取決於三個條件：有理論依據、用迴歸或路徑分析區分自變數與依變數、有納入控制變數。這句看不出你是否三項都有。
- 改法：全句統一強度，並把方向與統計量寫進同一個陳述裡，不需要「因此……」那一段。

### 錯誤（用語）
- 「數據」：大陸用語，作為 data 時台灣寫「資料」。
- 「人工智能」：大陸用語，台灣寫「人工智慧」。這是最顯眼的標記。

### 瑕疵（是否要修由你判斷）
- 「之」出現四次（本研究之、人工智能之、受試者之、顯著之），文言腔偏重，讀起來生硬。改成「的」或直接刪掉。
- 「存在……關係」是弱動詞加抽象名詞，可還原成「正相關」或「正向預測」。「兩者之間」也多餘。
- 句子沒有統計量。「顯著」後面應附上 β 與 p 值，否則讀者無從判斷效果大小。

### 通過項目
- 「受試者」用法正確（台灣用語）。
- 標點使用全形逗號與句號，符合慣例。

### 整合修改版
請依你的研究情況二選一：

**若三個條件都滿足（有理論依據、迴歸或路徑分析、有控制變數）：**
> 本研究資料顯示，人工智慧使用行為對受試者的學習成效具有顯著正向影響（β = ＿，p < ＿）。

**若條件不滿足（例如只有相關分析、沒有控制變數）：**
> 本研究資料顯示，人工智慧使用行為正向預測受試者的學習成效（β = ＿，p < ＿）。

兩個版本都把「正向」放進主要陳述，並刪掉「因此可以得知」那一段。β 與 p 請填入你的實際結果。
