## 學術寫作品質稽核結果

### 致命（因果越線、自創術語）

1. **「導致」用在自己的橫斷面結果**
   - 原句：「知覺易用性則導致學生的持續使用意圖顯著提升（β = .22, p < .01）」
   - 問題：這是橫斷面路徑係數，「導致」的因果強度超出證據。上一句的知覺有用性用「具有顯著正向影響」，三個條件（TAM 理論、路徑分析、控制性別與年級）都具備，這種寫法合格。同一段兩個係數用不同強度的動詞，口試委員會抓這種前後不一致。
   - 改法：「知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）」

2. **自創路徑名稱「認知卸載侵蝕路徑」**
   - 原句：「此結果支持本研究提出的『認知卸載侵蝕路徑』」
   - 問題：這是把自己的推論包裝成已建立的構念。
   - 改法：改用描述性語言，例如「知覺有用性與依賴程度的關聯」。

3. **結論超出資料能支持的範圍**
   - 原句：「亦即學生把思考外包給AI之後，自主除錯能力隨之流失」
   - 問題：
     - 你的資料只顯示知覺有用性與依賴程度正相關，沒有測量自主除錯能力。
     - 「之後……隨之」又暗示時間先後與因果，橫斷面資料無法檢驗。
     - 「此結果支持」「過去研究也有類似發現」都把 Bastani 等人（2024）的實驗結果當成自己路徑的證據。他們的結果是閉卷測驗表現下降，並非除錯能力流失，也沒有檢驗你的路徑。
     - 「因此，教師在課程設計上應考量……」從相關結果直接跳到教學建議，推論跳得太快。
   - 改法：改寫成推測，並明說本研究沒有測量這項能力（見整合修改版）。
   - 補充：Bastani 等人用隨機分派實驗，引述其結果時用「導致」沒有問題。

### 整合修改版

> 本研究以科技接受模型為理論基礎，採橫斷面問卷調查，探討大學生持續使用生成式AI輔助程式設計的意圖。研究者透過網路問卷蒐集資料，共回收有效問卷 312 份，所有題項皆以 Likert 七點量表測量。資料以 SmartPLS 4 分析，並將性別與年級納入控制變數。
>
> 分析結果顯示，在控制性別與年級後，知覺有用性對持續使用意圖具有顯著正向影響（β = .41, p < .001），此結果與 Davis（1989）的主張一致。知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。另外，依賴程度與持續使用意圖呈顯著正相關（r = .38, p < .001）。
>
> 本研究進一步以多元迴歸分析檢驗依賴程度的前因，發現知覺有用性愈高的學生，依賴程度也愈高（β = ⟨待補⟩, p ⟨待補⟩）。這項結果與「學生愈認為AI有用，愈傾向依賴AI」的推論一致。然而本研究未測量自主除錯能力，無法檢驗過度依賴是否削弱這項能力。Bastani 等人（2024）以隨機分派實驗發現，練習期間使用未加限制的 GPT-4，導致學生在後續閉卷測驗的表現下降，顯示依賴AI可能對學習成效有不利影響。教師在課程設計上可留意生成式AI對學習的潛在衝擊，後續研究宜直接測量自主除錯能力，以檢驗這項推測。
