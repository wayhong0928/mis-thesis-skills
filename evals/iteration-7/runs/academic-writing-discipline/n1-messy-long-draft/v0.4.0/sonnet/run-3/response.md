## 學術寫作品質稽核結果

這段文字的主要問題是因果語言越線，以及討論部分的主張超出資料能支持的範圍。用語和格式問題數量不多，修起來很快。

### 致命

1. **「導致」用在橫斷面結果**
   - 原句：「知覺易用性則導致學生的持續使用意圖顯著提升（β = .22, p < .01）」
   - 問題：這是自己的橫斷面路徑係數，「導致」的因果強度太高。上一句才用「具有顯著正向影響」，同一段內動詞強度前後不一致，口試委員最常從這裡切入。
   - 改法：「知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。」
   - 補充：你有理論、路徑分析和控制變數三個條件，所以第一句的「具有顯著正向影響」合格，不用改。

2. **自創路徑名稱**
   - 原句：「認知卸載侵蝕路徑」
   - 問題：這是自創術語，包裝成像已建立的構念。「認知卸載」本身是既有概念，但「侵蝕路徑」不是。
   - 改法：改用描述性語言，例如「依賴程度在知覺有用性與自主能力之間的中介效果」。你沒有測這條路徑，所以這個說法也不能用。

3. **主張強度超出證據**
   - 原句：「此結果支持……亦即學生把思考外包給AI之後，自主除錯能力隨之流失。」
   - 問題：你的資料只顯示知覺有用性較高的學生依賴程度也較高。這裡沒有測量自主除錯能力，也沒有時間先後，所以「思考外包之後能力流失」沒有被你的資料檢驗過，「支持」兩字不成立。
   - 改法：說明結果與認知卸載觀點一致，並明講本研究未測量能力變化（見整合修改版）。

### 錯誤

- **大陸用語**
  - 「通過網路問卷收集數據」改成「透過網路問卷蒐集資料」。
  - 「多元回歸分析」改成「多元迴歸分析」。
- **譯名不一致**：「知覺有用性」與「感知有用性」交替出現，全篇統一用「知覺」，因為「知覺易用性」已經用了。
- **引用格式**：「Bastani et al.（2024）」在中文行文中改成「Bastani 等人（2024）」。

### 瑕疵（是否修改由你判斷）

- **證據類型不對等**
  - 「過去研究也有類似發現」把你的橫斷面相關，和 Bastani 等人的隨機實驗放在一起說「類似」。
  - 最後一句「因此，教師……」的前提主要來自別人的實驗，不是你的資料，建議用「提示」語氣。
- **統計報告不完整**
  - 方法只提 SmartPLS，後面卻突然出現「多元迴歸分析」，也沒有報告係數。
  - 建議交代為何另用迴歸，並補上 β 與 p 值。

### 通過項目

- Bastani 等人那句的「導致」：引用隨機分派實驗，屬於可用因果語言的例外，不用改。
- 知覺有用性那句的「具有顯著正向影響」：三條件齊備。
- 依賴程度與意圖的「顯著正相關」：相關係數配相關語言，一致。
- 弱動詞、「存在」濫用、連接詞、全形標點：未見問題。

### 整合修改版

> 分析結果顯示，在控制性別與年級後，知覺有用性對持續使用意圖具有顯著正向影響（β = .41, p < .001），此結果與 Davis（1989）的主張一致。知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。另外，依賴程度與持續使用意圖呈顯著正相關（r = .38, p < .001）。
>
> 本研究進一步以多元迴歸分析檢驗依賴程度的前因（β = .xx, p < .xx），發現知覺有用性愈高的學生，依賴程度也愈高。此結果與認知卸載的觀點一致：學生愈認為生成式 AI 有用，可能愈傾向把思考交給 AI。然而，本研究未測量自主除錯能力，無法檢驗依賴是否削弱此能力，有待縱貫研究或實驗研究驗證。Bastani 等人（2024）以隨機分派實驗發現，練習期間使用未加限制的 GPT-4，導致學生在後續閉卷測驗的表現下降。這項實驗證據提示，教師在課程設計上宜留意生成式 AI 對學習的潛在衝擊。

方法段的「通過網路問卷收集數據」也要一併改成「透過網路問卷蒐集資料」。
