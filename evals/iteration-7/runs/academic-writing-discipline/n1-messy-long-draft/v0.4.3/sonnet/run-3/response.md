## 學術寫作品質稽核結果

### 致命（因果動詞越線／超出證據）

- **原句**：「知覺易用性則導致學生的持續使用意圖顯著提升（β = .22, p < .01）。」
  **問題**：這是橫斷面問卷的路徑係數，「導致」的因果強度超出證據。同一段前一句對知覺有用性寫的是「具有顯著正向影響」，兩句動詞強度也不一致。
  **改法**：「知覺易用性對持續使用意圖具有顯著正向影響（β = .22, p < .01）。」

- **原句**：「此結果支持本研究提出的『認知卸載侵蝕路徑』」
  **問題**：「認知卸載侵蝕路徑」是自創的路徑名稱，讀起來像已建立的構念。
  **改法**：改用描述性語言，例如「認知卸載的假設」或「知覺有用性經由依賴程度……的歷程」。

- **原句**：「亦即學生把思考外包給AI之後，自主除錯能力隨之流失。」
  **問題**：你的資料只顯示知覺有用性愈高，依賴程度愈高。「外包思考之後」是時序，「能力流失」是結果，兩者都沒有被測量，也無法由橫斷面資料得出。「支持」這個動詞因此用得太強。
  **改法**：把它降為待檢驗的推論，並明說本研究沒有測量除錯能力（見整合修改版）。

### 整合修改版

> 本研究以科技接受模型為理論基礎，採橫斷面問卷調查，探討大學生持續使用生成式AI輔助程式設計的意圖。研究者透過網路問卷蒐集資料，共回收有效問卷 312 份，所有題項皆以 Likert 七點量表測量。資料以 SmartPLS 4 分析，並將性別與年級納入控制變數。
>
> 分析結果顯示，在控制性別與年級後，知覺有用性對持續使用意圖具有顯著正向影響（β = .41, p < .001），此結果與 Davis（1989）的主張一致〔待核對〕。知覺易用性對持續使用意圖亦具有顯著正向影響（β = .22, p < .01）。另外，依賴程度與持續使用意圖呈顯著正相關（r = .38, p < .001）。
>
> 本研究進一步以多元迴歸分析檢驗依賴程度的前因，發現知覺有用性愈高的學生，依賴程度也愈高〔請補 β 與 p 值〕。此結果與本研究提出的認知卸載假設方向一致：學生愈依賴AI，可能愈少自行思考，進而影響自主除錯能力。不過，本研究未測量除錯能力，無法檢驗這一推論〔請確認〕。過去研究也有類似的疑慮，Bastani 等人（2024）以隨機分派實驗發現，練習期間使用未加限制的 GPT-4，導致學生在後續閉卷測驗的表現下降〔待核對〕。基於此，教師在課程設計上宜考量生成式AI對學習的潛在衝擊。
