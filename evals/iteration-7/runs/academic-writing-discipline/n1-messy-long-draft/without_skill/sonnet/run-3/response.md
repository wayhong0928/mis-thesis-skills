## 主要問題（建議優先處理）

**1. 橫斷面資料卻用因果語言**
- 「知覺易用性則導致學生的持續使用意圖顯著提升」：橫斷面問卷只能說「正向預測」或「顯著相關」，不能說「導致」。
- 「學生把思考外包給AI之後，自主除錯能力隨之流失」是時間先後加因果，橫斷面設計看不出來。

**2.「認知卸載侵蝕路徑」沒有被資料支持**
- 你的資料只測了知覺有用性、知覺易用性、依賴程度、持續使用意圖。
- 沒有測量「自主除錯能力」，也沒有任何前後變化。
- 「有用性越高，依賴越高」只說明兩者有關聯，不等於能力被侵蝕。
- 依賴程度與持續使用意圖是正相關（r = .38），這反而說明依賴與意圖共變，並沒有顯示「侵蝕」。

## 方法與報告不一致

- **分析方法前後不一**：方法說用 SmartPLS 4，後面卻突然出現「多元回歸分析」，沒有說明理由，也沒說有沒有控制性別與年級。
- **統計量格式不統一**：前面用 β，依賴程度卻用 r。如果依賴程度在模型內，應報路徑係數 β。
- **關鍵結果缺數字**：「有用性 → 依賴程度」完全沒有 β、p 或 R²。
- **缺少 PLS 常見報告**：信效度（CR、AVE、HTMT）、VIF、bootstrapping 的信賴區間、R²、f²。
- **依賴程度沒有定義**：它不是 TAM 的原有構面，需要說明其測量方式，並區分它與「持續使用意圖」的概念重疊。
- **用語不一**：「知覺有用性」與「感知有用性」請統一。

## 其他

- **Davis（1989）的引用**：他談的是初始採用。你研究的是「持續使用」，可考慮補 Bhattacherjee（2001）的期望確認模型，或說明為何沿用 TAM。
- **教學建議**：結尾「教師應考量……」沒有從你的資料推導出來。建議寫得具體，並標明是推論，例如：「若依賴程度確實伴隨能力下降（本研究未檢驗），課程可考慮設計限制使用的練習階段」。
- **缺少限制說明**：沒有交代網路問卷的抽樣方式（可能是便利樣本）、自陳式偏誤、共同方法變異、橫斷面無法推因果。
