### 瑕疵（是否修改由你決定）
- **第二句中間肥大**
  原句：「依據科技接受模型，以 PLS-SEM 分析並控制性別與年級後，知覺有用性（β = .41, p < .001）與知覺易用性（β = .22, p < .01）對持續使用意圖皆具有顯著正向影響。」
  問題：主詞很晚才出現，主要動詞又被兩組統計數字隔開，讀者要憋到句尾才知道結論。

### 整合修改版
本研究以 312 位修習程式設計課程的大學生為對象，採橫斷面問卷調查。依據科技接受模型，本研究以 PLS-SEM 分析資料，並控制性別與年級。結果顯示，知覺有用性（β = .41, p < .001）與知覺易用性（β = .22, p < .01）對持續使用意圖皆具有顯著正向影響。這兩項結果與 Venkatesh 等人（2012）在消費者情境的發現方向一致。然而，本研究的資料來自單一時間點，無法排除反向解釋：持續使用意圖較高的學生，可能本來就較常使用［工具名稱］，因而對有用性的評分也較高。後續研究可採縱貫設計確認時間先後。
