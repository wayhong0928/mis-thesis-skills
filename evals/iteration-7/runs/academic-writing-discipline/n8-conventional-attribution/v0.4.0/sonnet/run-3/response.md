## 學術寫作品質稽核結果

### 致命（誤植理論來源，屬誇大或誤述原作者主張）
- 原句：「本研究另參考 Bandura（1977）提出的科技接受模型，將自我效能納入研究模型。」
  問題：科技接受模型（TAM）是 Davis（1989）提出的，也就是你第一句寫的那個。Bandura（1977）提出的是自我效能理論，源自社會學習／社會認知理論，與科技接受無關。這句把兩個理論的出處混在一起，口試委員很容易一眼看出。
  改法：
  1. 把 Bandura（1977）改成自我效能概念的出處。
  2. 把「科技接受模型」另外交代為 Davis 的模型，不要再掛在 Bandura 名下。
  3. 說明為何把自我效能放進 TAM，最好補一篇做過這件事的文獻。

### 瑕疵（是否要修由你判斷）
- 原句：整段三句。
  問題：三句各講一個理論，句與句之間沒有銜接，沒說明這三者和你的研究模型有什麼關係。讀者看完只知道你列了三個理論，不知道它們各自負責模型的哪一塊。
  改法：在整合版末句補一句連結，說明自我效能在模型中的角色。我不知道你的模型細節，所以用 ⟨ ⟩ 留空，請你自己填。

### 通過項目
- 因果動詞：全段沒有越線。「受……影響」是在陳述 Ajzen 的理論主張，不是你自己的實證發現，可以保留。
- Ajzen（1991）的描述：計畫行為理論的三個前因（態度、主觀規範、知覺行為控制）與原理論相符。
- Davis（1989）的描述：知覺有用性與知覺易用性兩個構念，也與原文相符。
- 引用格式：中文行文的敘述引用用全形括號，格式正確。
- 譯名：「知覺有用性」「知覺易用性」前後一致。
- 用語與標點：沒有大陸用語，標點沒有問題。

### 整合修改版
Davis（1989）提出知覺有用性與知覺易用性兩個構念，用來解釋使用者對資訊科技的接受程度。Ajzen（1991）提出計畫行為理論，認為行為意圖受態度、主觀規範與知覺行為控制三者影響。Bandura（1977）提出自我效能的概念，指個人對自己能否完成特定行為的信念。本研究據此將自我效能納入科技接受模型，⟨說明自我效能在模型中的角色，例如作為知覺易用性的前因，並補上做過這種延伸的文獻引用⟩。
