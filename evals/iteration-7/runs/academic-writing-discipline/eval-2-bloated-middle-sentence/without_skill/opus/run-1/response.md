# 有中間肥大的問題，而且是這句話最主要的毛病

這句話的主幹其實很短：**大學生依賴 AI → 本研究探討其影響**。但中間那段塞了太多虛詞和名詞化結構，主詞跟關鍵動詞被拉得很遠。

## 中間段的問題

> 使得越來越多的大學生**開始在**課業與報告撰寫**的過程中**，**對於**這類工具**的使用產生了高度的依賴性**

| 冗詞 | 問題 |
|---|---|
| 開始 | 語意很弱，刪掉不影響意思 |
| 在……的過程中 | 「在課業與報告撰寫上」就夠了 |
| 對於……的使用 | 依賴的是工具本身，不用加上「的使用」 |
| 產生了高度的依賴性 | 把動詞「依賴」改成名詞，再補一個空動詞「產生」，直接寫「高度依賴」就好 |

## 其他順帶的問題

1. **「由於……使得……」缺主詞**：這是常見的病句。「由於」已經表示原因，再加「使得」，整句就沒有主語了。兩個詞留一個就好。
2. **因果鏈太長**：「由於……使得……因此……」一句話串了三層因果，讀者會喘不過氣。建議拆成兩句，先寫背景，再寫研究目的。
3. **句尾也有點肥**：「希望能夠深入探討……究竟會……造成什麼樣的影響」，其中「希望能夠」「究竟」「什麼樣的」都可以精簡。

## 修改建議

**精簡版：**
> 近年生成式AI快速普及，越來越多大學生在課業與報告撰寫上高度依賴這類工具。本研究旨在探討此依賴傾向對學習成效的影響。

**如果想保留一點語氣：**
> 隨著生成式AI技術快速發展與普及，越來越多大學生在撰寫課業與報告時高度依賴這類工具。本研究即在探討此種依賴傾向如何影響學生的學習成效。

原句約 90 字，改完後大約 50 字，資訊量沒有減少。
