## 學術寫作品質稽核結果

只列問題，沒有改寫。依判準逐項對照過這段，原句都附在下面。

### 致命

- **原句**：「部分學者認為過度依賴會導致學生的學習能力下降」
  - **問題 1**：「導致」是門檻最高的因果動詞，轉述他人主張時也一樣。只有原作者靠隨機實驗等可信識別策略支持因果時，才能用因果語言轉述。這句沒有出處，你無從說明這些學者的證據強度。
  - **問題 2**：前一句 Lee 等人是「呈負相關」，這句卻跳到「導致下降」。兩句相鄰，讀者會以為後者是前者的延伸。相關語言接因果語言，是口試委員最常切入的地方。
  - **問題 3**：前一句談「批判思考」，這句談「學習能力」，是兩個不同的構念。

### 錯誤

- **原句**：「Lee 等人（2025）通過問卷調查發現」
  - **問題**：介系詞用法的「通過」是大陸用語，台灣慣用「透過」。
- **原句**：「部分學者認為……」
  - **問題**：沒有任何引用，APA 要求這類轉述要附出處。「部分學者」也無法讓讀者查證。

### 瑕疵（是否修由你判斷）

- **「被廣泛使用」**
  - 文獻回顧與緒論應避免被動，改回主動陳述。
  - 「廣泛」是未經支持的程度判斷，沒有引用或數據。
- **「對於如何在教學中適當引入生成式AI的問題，值得深入探討」**
  - 這是中間肥大的易爆句型「對於……的問題」，主要動詞拖到句尾才出現。
  - 「因此」接得不順：前面是「學者認為會下降」，後面是「如何引入值得探討」，因果連接沒有撐起來。
  - 「值得深入探討」是空泛結語，沒說明要探討什麼。
  - 「適當」沒有界定。
- **用語前後漂移**
  - 「依賴程度」變成「過度依賴」，連續兩句換了說法。「依賴」與「過度依賴」不是同一個東西，建議統一。
  - 「批判思考」在台灣也常寫「批判性思考」，選一個用到底。
- **「生成式AI」首次出現**
  - 建議寫全稱「生成式人工智慧（generative AI）」，之後再用簡稱。
  - 中文與英文縮寫之間的空格目前不一致：「Lee 等人」有空格，「生成式AI」沒有。
- **Lee 等人的結果只有方向，沒有數值**
  - 引用文獻時，補上相關係數或樣本描述，讀者才知道「負相關」的強度。這是 AI 感的特徵之一：只講方向，不附統計量。

### 通過項目

- 「Lee 等人（2025）」的「等人」寫法正確。
- 「呈負相關」與橫斷面問卷的證據強度相符，沒有越線。
- 全形標點與逗號使用一致。
