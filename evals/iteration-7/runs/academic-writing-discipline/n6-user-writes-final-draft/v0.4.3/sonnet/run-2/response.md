### 致命（因果動詞越線）
- 原句：「部分學者認為過度依賴會導致學生的學習能力下降」
  - 問題一：「導致」是門檻最高的因果動詞。整段沒有交代這些學者的證據強度，句子又沒有標明這是他們的主張。
  - 問題二：前一句 Lee 等人是問卷的「負相關」，這一句直接跳成「導致」。同一段內相關語言滑成因果語言，是口試最容易被追問的地方。

### 瑕疵（是否修由你判斷）
1. **構念前後滑動**：
   - Lee 測的是「依賴程度」與「批判思考」。下一句變成「過度依賴」與「學習能力」。

   - 「批判思考」和「學習能力」是不同構念。讀者會覺得兩句在互相佐證，其實它們談的不是同一件事。
2. **「對於如何……的問題，值得深入探討」中間肥大**：

3. **「值得深入探討」是空泛結語**：它沒有說現有研究缺了什麼，這句話拿掉，段落的論點不變。
4. **「被廣泛使用」**：
   - 文獻回顧宜避免被動，主詞也不明。
   - 「廣泛」是強度判斷，卻沒有來源或數據支撐。

   - 首次出現宜給全稱與英文（生成式人工智慧〔generative AI〕）。
