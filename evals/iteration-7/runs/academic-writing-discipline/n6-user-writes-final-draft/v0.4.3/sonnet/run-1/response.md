## 學術寫作品質稽核結果

這次只列問題，沒有附整合修改版或改寫句。

### 致命（因果與相關語言前後不一致）
- 原句：「Lee 等人（2025）通過問卷調查發現，學生對AI的依賴程度與批判思考呈負相關。此外，部分學者認為過度依賴會導致學生的學習能力下降……」
  - 問題：前一句是相關語言（「呈負相關」），後一句直接跳到「導致」。同一段裡，證據只支持相關，下一句卻用絕對因果。「導致」的門檻最高，而且沒有任何實證支撐：「部分學者」沒有引用，看不出他們的證據是實驗還是橫斷面調查。
  - 方向：先確認這些學者的證據類型。如果是橫斷面或問卷，就用「相關」「預測」。如果是隨機實驗，才能保留因果語言，而且要標出引用。這一句也不要寫成像是 Lee 等人的結果延伸出來的。

### 錯誤（用語）
- 原句：「通過問卷調查發現」
  - 問題：「通過」作介系詞是大陸用法。
  - 方向：改成「透過」。

### 瑕疵（是否修由你判斷）
1. **「因此」的推論不成立**
   - 原句：「因此對於如何在教學中適當引入生成式AI的問題，值得深入探討」
   - 問題：前兩句談的是依賴與批判思考、學習能力的負面關係。這不必然推出「該探討如何適當引入」。中間還缺一步，例如「現有研究多只談風險，沒有談怎麼引入」。
2. **中間肥大句型**
   - 原句：同一句的「對於如何……的問題」。
   - 問題：「對於……的問題」是易爆句型，主要動詞「探討」被推到最後。
   - 方向：把動詞前移。
3. **「過度」與「適當」都沒有界定**
   - 問題：「過度依賴」和「適當引入」都是沒有標準的程度詞。
   - 方向：讀者會問多少算過度、什麼算適當。第二章至少要交代這兩個詞的操作定義，或指出文獻裡怎麼界定。
4. **術語不一致**
   - 問題：第一句寫「生成式AI」，第二句 Lee 等人那裡只寫「AI」，同一構念用了兩種說法。這也牽涉到 Lee 的研究對象是不是生成式 AI（見待核對）。
   - 方向：全篇統一一個名稱。
5. **構念換了名字**
   - 問題：Lee 等人談「批判思考」，後一句變成「學習能力」。這是兩個不同構念，讀者會以為在講同一件事。
6. **空泛收尾**
   - 原句：「值得深入探討」
   - 問題：這是典型的空泛結語，沒有說出具體缺口。
7. **被動式與無支撐的開頭**
   - 原句：「被廣泛使用」
   - 問題：文獻回顧段落宜改回主動陳述，而且「廣泛」沒有數據或引用支撐。「近年來」開頭也偏籠統。
8. **話題漂移，缺主題句**
   - 問題：三句分別是使用現況、依賴與批判思考、學習能力與如何引入，話題每句一轉。段落沒有一句明講這段要證明什麼。

### 待核對（我沒有原文，無法確認）
- Lee 等人（2025）的研究樣本和情境：是不是程式設計教育的學生？樣本是單一學校還是跨校？
- 「依賴程度」和「批判思考」的測量方式：問卷是自評量表嗎？結論有沒有寫成「負相關」，還是你轉述時加了強度？
- Lee 研究的 AI 是不是特指生成式 AI。
- 「部分學者」指的是誰、年份和證據類型。這一句目前沒有引用，要補上。

### 通過項目
- 「Lee 等人（2025）」的引用格式正確，中文行文用「等人」。
- 「呈負相關」這個動詞強度，以問卷調查的證據來說是恰當的。
- 全形標點使用一致。

### 一句話總結
需修（致命 1 處、錯誤 1 處、瑕疵 8 處，另有 4 項待核對）。優先處理「導致」的因果越線和沒有引用的「部分學者」，因為口試委員最可能從這兩處追問。
