### 致命

**1. 從相關跳到因果**
- 原句：「部分學者認為過度依賴會導致學生的學習能力下降」
- 問題：上一句 Lee 等人（2025）是問卷調查，只能支持「負相關」。這句卻用「導致」，因果強度往上跳了一級。讀者會以為前一句的證據支持這個因果。
- 改法：
  - 這句如果是轉述他人的因果主張，就要標明那是對方的主張，並看對方的研究設計撐不撐得起「導致」。

### 錯誤

**2. 大陸用語**：「通過問卷調查」的「通過」是介系詞用法，台灣學術寫作用「透過」。

**4. 首句沒有來源，語氣也偏模糊**
- 「近年來」沒有年份範圍，「被廣泛使用」沒有數據或文獻支持。
- 「被廣泛使用」是被動句，文獻回顧裡建議改回主動陳述。

**5. 概念前後不一致**
- 第二句寫「依賴程度」，是連續變項。第三句變成「過度依賴」，多了「過度」這個評價性門檻，但前面並沒有證據說明多少算過度。
