## 學術寫作品質稽核結果

我沒有改寫整段，只列問題，每條附一句修正方向。

### 致命
1. **相關與因果語言前後不一致**
   - 原句：「Lee 等人（2025）……發現，學生對AI的依賴程度與批判思考呈負相關。」接著「過度依賴會導致學生的學習能力下降」。
   - 問題：前一句是問卷得到的相關，後一句升級成「導致」，而且沒有任何證據支撐這個因果。這是整段最容易被口試委員追問的地方。
   - 方向：如果這句要轉述學者的主張，就標明是誰的主張，並看對方的設計能不能支持因果語言（見下一條）。如果只是你自己的推論，改成相關或預測語言，或標成「可能」。

2. **「部分學者」沒有出處**
   - 問題：這句承擔論證，卻沒有引用，也看不出是哪些研究、什麼設計。「導致」要不要保留，取決於原研究是不是實驗或有因果識別的設計。
   - 方向：補上具體文獻。補不出來就不要放進論證主線。

### 錯誤
3. **大陸用語**：「通過問卷調查」的「通過」是介系詞用法，台灣慣用「透過」。
4. **構念前後不一致**：前面寫「依賴程度」和「批判思考」，後面變成「過度依賴」和「學習能力」。
   - 「過度依賴」和「依賴程度」是兩回事。前者預設依賴已經過量，但 Lee 等人只是測了依賴程度。
   - 「學習能力」和「批判思考」是不同構念，讀者會以為這兩句在講同一件事。
   - 方向：統一用語，或明講兩者的關係。
5. **「被廣泛使用」**：緒論與文獻回顧要避免被動語態，主詞也不明。「廣泛」沒有數據或文獻支持，需要補引用，或改成有範圍的說法。

### 瑕疵（是否修由你判斷）
6. **最後一句中間肥大，而且一句多話題**
   - 這句包含三個話題：學者的主張、引入AI的問題、值得探討。
   - 「對於……的問題」是中間肥大的典型句型，主要動詞「探討」拖到句尾。
   - 方向：把「學者的主張」和「研究問題」拆成兩句，各自有明確主語。
7. **邏輯連接不成立**
   - 「此外」暗示補充，但第二組內容其實是同一話題（依賴的壞處）的加強，不是另一件事。
   - 「因此」也接不上。從「過度依賴有害」到「所以要探討如何適當引入」少了一步，也就是為什麼不是禁用，或現有研究缺了什麼。
   - 方向：想清楚這兩個連接詞背後的關係，再決定要不要保留。
8. **空泛收尾**：「值得深入探討」「適當引入」都沒有內容。「適當」是什麼標準？「深入」到什麼程度？這段是第二章，讀者期待收在一個具體的缺口或問題上。
9. **證據偏薄**：全段實質引用只有一篇 Lee 等人，卻要支撐「依賴與批判思考負相關」的整個論述。這不是句子層級的錯，但審查時容易被問「只有一篇嗎」。
10. **第一次出現的「生成式AI」**：建議給完整名稱與英文，例如「生成式人工智慧（generative AI）」，之後再簡稱。另外，「Lee 等人」的中英文之間有空格，「生成式AI」沒有，排版要統一。
