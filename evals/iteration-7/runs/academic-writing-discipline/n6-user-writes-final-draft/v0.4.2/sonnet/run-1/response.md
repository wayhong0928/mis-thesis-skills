## 稽核結果

依你的要求只列問題，不附修改稿。

### 致命

**1. 因果語言與相關語言前後不一致，而且沒有出處**
- 原句：「部分學者認為過度依賴會導致學生的學習能力下降」
- 上一句 Lee 等人（2025）是問卷調查，結論是「負相關」，這句卻跳到「導致」。同一段內從相關升級成因果，口試委員最容易從這裡切入。
- 「部分學者」沒有任何引用。讀者無法判斷這個因果主張是誰提的、證據是什麼，也看不出對方是不是有因果識別策略。
- 「導致」的門檻最高。如果某位學者的證據是橫斷面資料，轉述時要降成「預測」或「相關」。如果是隨機實驗，才能保留因果語言，而且要寫出作者與年份。
- 這句還有兩處概念漂移：「依賴程度」變成「過度依賴」，「批判思考」變成「學習能力」。Lee 等人量的是前者，這句談的是後者，兩個結果變項不同，卻被當成同一條證據線接起來。

### 錯誤

**2. 大陸用語**
- 「通過問卷調查」的「通過」是介系詞用法，改成「透過」。

**3. 同一構念出現兩種稱呼**
- 第一句與第三句寫「生成式AI」，第二句寫「AI」。全篇要固定一個稱呼，第一次出現時定義，之後都用同一個。

**4. 中間肥大加弱動詞，是「對於……的問題」句型**
- 原句：「因此對於如何在教學中適當引入生成式AI的問題，值得深入探討」
- 主題塞在「對於……的問題」裡，主要動詞「探討」拖到句尾才出現。
- 「的問題」多半可以刪。「值得深入探討」是「進行討論」同類的弱動詞化寫法，由研究者直接說出要做什麼更好。
- 這句同時要接上一句的因果、又開出新主題，話題也在漂移。

### 瑕疵（是否要修由你判斷）

**5. 第一句沒有出處，也有被動語態和空泛字眼**
- 原句：「近年來，生成式AI在程式設計教育中被廣泛使用」
- 「近年來」「被廣泛使用」沒有任何數據或文獻支持。這是文獻回顧章，「被廣泛使用」可以改回主動陳述，或補上具體的使用比例。

**6. 連接詞**
- 「此外」暗示第三句和第二句是並列補充，但實際上第三句是在反方向提出疑慮，「此外」不是最準確的連接。
- 「因此」把「學者認為會下降」推到「值得探討如何引入」，中間有一步沒說出來：為什麼是「如何引入」，而不是「是否引入」。這是構句層的跳接，不是我要處理的論證檢查，你自己決定要不要補。

**7. 結尾是空泛收束**
- 「值得深入探討」屬於讚揚式或呼籲式結語，沒說要探討什麼、缺的是什麼。

**8. 排版**
- 「Lee 等人」中英之間有空格，「生成式AI」沒有。全篇統一即可。
