### 整合修改版
本研究採用問卷調查法蒐集資料，研究對象為北部三所大學的大學生，共 256 人。依 Fornell 與 Larcker（1981）的建議，本研究檢驗了收斂效度與區辨效度，兩者均符合標準，模型適配指標亦達可接受水準。此外，Venkatesh 等人（2012）指出，習慣可預測持續使用意圖，故本研究將習慣納入控制變數。Hair 等人（2017）建議樣本數至少為最大路徑數的十倍，本研究的樣本數符合此要求。
