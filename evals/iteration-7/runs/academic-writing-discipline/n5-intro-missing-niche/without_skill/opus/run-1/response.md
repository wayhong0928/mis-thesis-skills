# 緒論第一節草稿意見

整體來說，文字通順，研究主題也清楚。目前最大的問題是**從背景直接跳到研究目的，中間少了「為什麼這個問題值得研究」的論證**。口試委員最常追問的就是這一段。

## 主要問題

### 1. 「因此」的推論不成立（最需要修改）
第一段只說了「生成式AI很普及，政府也重視」，第二段就用「因此」帶出「探討依賴程度與科技焦慮、自我效能」。讀者會問：
- 普及為什麼是問題？依賴會造成什麼後果？例如削弱除錯能力、只會複製貼上、後設認知下降、學術誠信問題。
- 為什麼要研究**依賴**，而不是使用意圖或接受度？
- 為什麼挑**科技焦慮**和**自我效能**這兩個變項？它們和依賴有什麼理論上的關聯？

建議在兩段之間補上「問題陳述」和「研究缺口」：
- 現有研究多半探討什麼，例如 TAM／UTAUT 的使用意圖、一般學科情境
- 比較少探討什麼，例如程式設計情境、「依賴」這個構念、心理特質作為前因
- 本研究要補上的就是這個缺口

### 2. 關鍵陳述缺少證據
- 「許多大學生已使用 ChatGPT 等工具完成課業」：需要調查數據或文獻支持，例如國內外的使用率調查。
- 「程式設計課程尤其常見」：這是你選這個情境的理由，更需要引用來支持，否則看起來只是主觀判斷。

### 3. 「依賴」的意涵要先定調
「依賴」在中文裡帶有負面色彩。你要先說清楚，你把它看成問題行為（類似過度依賴、成癮），還是中性的使用程度？這會影響後面的假設方向和量表選擇。第一節可以先簡短交代，詳細定義留到名詞釋義或第二章。

### 4. 章節配置
一般碩論第一章的結構是：
- 第一節 研究背景與動機
- 第二節 研究目的與問題
- 第三節 名詞釋義
- 第四節 研究範圍與限制

所以：
- **研究目的**建議獨立成一節，並改寫成條列式的研究問題，例如：「一、大學生在程式設計課程中對生成式AI的依賴程度為何？二、科技焦慮是否能預測……」
- **PLS-SEM** 屬於研究方法的細節，放在第三章就好，第一節不需要提。
- **章節安排**（「本論文共分五章……」）通常放在第一章最後一節，或者乾脆省略，因為很多學校並不要求。

### 5. 小地方
- 教育部指引請再核對正式名稱和發布月份，第一次提到時寫出全名會比較嚴謹。
- 「科技焦慮」和「自我效能」最好寫清楚指的是什麼，例如「AI焦慮」或「程式設計自我效能」。範圍不同，後面的量表也會不同。

## 建議的第一節段落架構

1. **現況**：生成式AI在高教和程式設計學習中普及（附數據）
2. **政策脈絡**：教育部指引，說明官方對「適當使用」的關注
3. **問題**：過度依賴對程式設計學習可能造成的負面影響（附文獻）
4. **缺口**：既有研究的不足，以及為什麼要從個人心理特質（科技焦慮、自我效能）切入（附理論依據）
5. **研究動機收束**：本研究想回答什麼，以及對教學實務有什麼意義
