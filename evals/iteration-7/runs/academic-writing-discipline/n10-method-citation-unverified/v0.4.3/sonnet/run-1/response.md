## 1. 樣本數：Hair 等人（2019）的引用有問題

- **「100 至 200」我無法對應到 Hair 等人（2019）的建議。** 這個區間比較像傳統共變結構 SEM（CB-SEM）的經驗法則，不是 PLS-SEM 的標準。
- Hair 等人（2019）談樣本數時，主張用檢定力分析（如 G*Power），或參考 Kock 與 Hadaya（2018）的逆平方根法、gamma-exponential 法。他們不主張給一個固定區間。
- 「10 倍法則」只是粗略下限，近年文獻並不鼓勵單獨依賴它。
- 「預計收集 200 份有效問卷」缺少依據。審查者通常會問：模型中指向單一潛在變數的最大箭頭數是多少？預期的最小 R² 或路徑係數是多少？檢定力和顯著水準設為多少？
- 實務上也要說明回收量。「200 份有效」代表實際發放要多於 200，無效問卷的預估比例也應交代。

## 2. 中介效果：Zhao 等人（2010）被誤用了

這是最嚴重的問題。Zhao 等人（2010）的論點正好相反：

- 他們批評 Baron & Kenny 的作法，也不建議用「直接效果是否顯著」來區分完全中介和部分中介。
- 中介成立的唯一條件，是間接效果（a×b）經 bootstrap 檢定後顯著。
- 他們提出的分類有五種，依間接效果和直接效果的顯著性與方向而定：
  - **互補中介（complementary）**：a×b 與 c 同號，且都顯著。
  - **競爭中介（competitive）**：a×b 與 c 異號，且都顯著。
  - **僅間接效果（indirect-only）**：只有 a×b 顯著。
  - **僅直接效果（direct-only）**：只有 c 顯著，無中介。
  - **無效果（no-effect）**：兩者皆不顯著。
- 所以「依間接與直接效果是否顯著，判定為完全或部分中介」，是把 Zhao 的框架換回舊的 Baron & Kenny 思路。

## 3. 其他缺漏

- **沒有交代為什麼選 PLS-SEM。** 常見理由是以預測為導向、模型複雜、有反映式與形成式混合的構面，或資料不符常態。Hair 等人（2019）正好有一套「何時該用」的說明可以引用。
- **沒有說明 bootstrap 設定。** 要寫出重抽樣次數（通常 5,000）和信賴區間類型。
- **沒有寫評估流程。** 一般會交代：
  - 測量模型：信度、收斂效度、區別效度（HTMT）。
  - 結構模型：VIF、R²、f²、Q²，必要時加 PLSpredict。
  - 若是單一來源問卷，還要處理共同方法變異。
