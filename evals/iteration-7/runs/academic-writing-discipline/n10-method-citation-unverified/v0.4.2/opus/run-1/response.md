這段有兩個引用和內容對不上的問題，口試委員很可能會問。第一個比第二個嚴重。

## 問題一：Zhao 等人（2010）的觀點被引反了

這是最需要改的地方。Zhao、Lynch 與 Chen（2010）這篇論文就是在批評 Baron 與 Kenny（1986）的「完全中介／部分中介」二分法，你的寫法剛好把它引成支持二分法的出處。

他們主張的重點有三個：
- 只要間接效果（a×b）顯著，就成立中介，不需要先確認總效果 c 顯著。
- 檢定間接效果應該用 bootstrap，不要用 Sobel test 或逐步法。
- 中介分成三種類型（另有兩種「無中介」）：

| 類型 | 間接效果 a×b | 直接效果 c' |
|---|---|---|
| 互補型中介（complementary） | 顯著 | 顯著，且與 a×b 同號 |
| 競爭型中介（competitive） | 顯著 | 顯著，且與 a×b 異號 |
| 僅間接中介（indirect-only） | 顯著 | 不顯著 |
| 僅直接、無中介（direct-only） | 不顯著 | 顯著 |
| 無效果、無中介（no-effect） | 不顯著 | 不顯著 |

另外，他們也特別指出「完全中介」這個說法容易讓人以為已經沒有遺漏的中介變項，所以不建議使用。照你原本「看直接效果顯不顯著」的判斷方式，也分不出互補型和競爭型，因為兩者的差別在正負號。

## 問題二：樣本數的依據站不住

1. **出處的問題**：據我所知，Hair 等人（2019）沒有提出「PLS-SEM 樣本一般落在 100 至 200」的建議。100 至 200 比較接近 CB-SEM 圈流傳的經驗值，例如 Hoelter 的 critical N = 200。這點我無法替你逐頁核對，請回原文確認你引的頁碼是否真的有這句話。
2. **推論的問題**：就算多數研究的樣本都在 100 到 200 之間，這也只是在描述一般情形，不足以說明你的模型需要多少樣本。審查者會想看到依你自己的模型計算出來的最低樣本數。
3. **實務的問題**：「預計收集 200 份有效問卷」沒有考慮無效問卷的比例，發放數量應該多抓一些。

建議改用下面其中一種方式估算：
- **G*Power 檢定力分析**：以「指向同一個內生構念的路徑數最多」的那一段模型為準，設定 f² = 0.15、α = .05、檢定力 = .80。
- **反平方根法**（Kock & Hadaya, 2018）：n_min > (2.486 / |β_min|)²。例如預期最小路徑係數是 0.2，算出來至少需要 155 份。

## 修改範例

> 本研究採 PLS-SEM 進行分析。樣本數依 Kock 與 Hadaya（2018）的反平方根法估算：假設模型中最小路徑係數為 0.20，在顯著水準 .05、檢定力 .80 的條件下，最低樣本數為 155 份。考量可能的無效問卷，本研究預計發放 ○○ 份，以取得至少 200 份有效問卷。中介效果依 Zhao 等人（2010）的建議，以 bootstrap 法（5,000 次重抽）檢定間接效果，並依間接效果與直接效果的顯著性及正負號，區分為互補型中介、競爭型中介、僅間接中介或無中介。

如果指導教授要求一定要用「完全／部分中介」的說法，可以在文中補一句對應關係：「僅間接中介」約等於完全中介，「互補型中介」約等於部分中介。但這組對應不能說是 Zhao 等人的主張。
