這段有三個問題,其中兩個是引用與原文主張不符,審查時很容易被挑出來。

## 1. Hair 等人(2019)的樣本數說法

「PLS-SEM 樣本數一般落在 100 至 200 之間」這個說法,我印象中 Hair 等人(2019)並沒有提出。他們反而批評過「10 倍法則」這類經驗法則,建議以統計檢定力分析來決定樣本數。原文頁碼請你自行核對。

**建議改法:**
- 改用 G*Power,例如 f² = 0.15、檢定力 0.80、α = 0.05,預測變數數取模型中指向單一潛在變數的最大箭頭數。
- 或用 Kock & Hadaya(2018)的 inverse square root method。這個方法下,200 份是否足夠取決於預期最小路徑係數:
  - 約 0.20 時,至少需要約 155 份。
  - 約 0.15 時,約需 275 份。
  - 約 0.10 時,約需 619 份。
- 把「200 份」寫成計算結果,不要寫成引用一個範圍。
- 另外,用 PLS-SEM 的理由應該是模型複雜、偏重預測、有形成性構面或資料非常態,不要只靠樣本數小。

## 2. Zhao 等人(2010)的中介判定

這段引用和原文主張相反。Zhao, Lynch & Chen(2010)批評 Baron & Kenny 的做法,不建議用「完全中介/部分中介」來分類,也不要求直接效果必須顯著。他們提出的做法是:

- 用 bootstrap 檢定間接效果(a×b)是否顯著。
- 再依直接效果(c)是否顯著及符號,分成五類:
  - **互補中介**(complementary):a×b 與 c 皆顯著且同號。
  - **競爭中介**(competitive):a×b 與 c 皆顯著但異號。
  - **僅間接中介**(indirect-only):a×b 顯著,c 不顯著。
  - **僅直接效果**(direct-only):a×b 不顯著,c 顯著。
  - **無效果**(no-effect):兩者皆不顯著。

**建議改法:**
- 依 Zhao 的分類法,並以 bootstrap 信賴區間檢定間接效果。
- 若想保留「完全/部分中介」的說法,應改引 Hair 等人(2017/2022)的 PLS-SEM 中介程序,並說明這與 Zhao 的分類如何對應。

## 3. 其他可補充之處

- **軟體與參數:** 例如 SmartPLS、bootstrap 5,000 次、百分位法信賴區間、單尾或雙尾。
- **抽樣方式與回收預估:** 「預計收集 200 份有效問卷」需要說明抽樣方法,以及實際發放量要多少才能涵蓋無效問卷。
- **模型評估步驟:** 測量模型的信度、收斂效度、區別效度,以及結構模型的共線性、R²、f²、Q²。
- **共同方法變異:** 說明如何處理。

## 修改範例

> 本研究採 PLS-SEM 分析,因研究模型包含多個潛在變數與中介路徑,且以解釋與預測內生變數為目的(Hair et al., 2019)。樣本數以 G*Power 3.1 估算:設定效果量 f² = 0.15、檢定力 0.80、α = 0.05,模型中指向單一構面的最大預測變數數為 X,所需最小樣本數為 N;並以 inverse square root method(Kock & Hadaya, 2018)交叉檢驗。據此,本研究預計回收至少 200 份有效問卷。中介效果以 bootstrap(5,000 次重抽樣)檢定間接效果之信賴區間,並依 Zhao 等人(2010)的分類,結合間接效果與直接效果的顯著性與方向,判定為互補中介、競爭中介、僅間接中介、僅直接效果或無中介效果。

其中 X 與 N 請代入你實際的計算結果。
