## 學術寫作品質稽核結果

三段的問題集中在第五章。第一章與第四章的因果用詞合格，第五章有兩處越線。

### 致命（因果動詞越線）

- **原句（第五章）：**「科技焦慮**導致**學生更頻繁地向生成式AI求助」
  - **問題：** 第四章是自己的橫斷面路徑係數，這裡卻用「導致」。「導致」暗示排除其他解釋後的確定性因果。橫斷面資料無法排除反向關係，例如常向AI求助的學生，焦慮反而變高或變低。這也使全篇動詞前後不一致：第一章和第四章用「影響」，第五章突然改用「導致」。口試委員最常從這種不一致切入質疑。
  - **改法：** 回到第四章的「具有顯著正向影響」，或改用「正向預測」。

- **原句（第五章）：**「顯示焦慮是學生**轉向**AI的**主要原因**」
  - **問題：** 這句有三層越線。
    1. 「主要原因」是在比較各種原因的相對大小，但模型只有 β = .29，沒有和其他因素比較，結果也不支持這個主張。
    2. 「原因」是絕對因果語言。
    3. 「轉向」暗示學生從別處改投AI，是一段時間上的轉變。橫斷面只能看到某一時間點上的個體差異，看不到轉變。
  - **改法：** 降成「科技焦慮是求助行為的相關因素之一」，並刪掉「轉向」。

### 瑕疵（是否修由你決定）

- **原句（第四章）：**「依據壓力因應理論建立模型，以 PLS-SEM 分析並控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向影響」
  - **問題：** 一句裡話題從「本研究」漂到「模型」，再到「科技焦慮」，主要動詞要到句尾才出現，有輕微的中間肥大。
  - **改法：** 拆成兩句，見下方整合修改版。

### 通過項目

- **第一章：**「影響為何？」是商管領域的慣例寫法，不列問題。它和第四章的動詞一致，這是優點。
- **第四章：**「具有顯著正向影響」站得住，三個條件都具備：有壓力因應理論、用 PLS-SEM 路徑分析、有控制性別、年級與程式設計經驗。
- **用語與格式：** 沒有大陸用語、標點錯誤或引用格式問題。

### 整合修改版

**【第一章】**（不需修改）
本研究欲回答：大學生的科技焦慮對其生成式AI求助行為的影響為何？

**【第四章】**（已套用瑕疵級的拆句，不想動可保留原句）
本研究為橫斷面問卷調查（N = 298），依據壓力因應理論建立模型，並以 PLS-SEM 分析。控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向影響（β = .29, p < .001）。

**【第五章】**
本研究發現，科技焦慮對大學生的生成式AI求助行為具有顯著正向影響（β = .29），與壓力因應理論的預期一致，顯示科技焦慮是求助行為的相關因素之一。惟本研究為橫斷面設計，無法排除反向關係或未納入模型的其他變數，因此結果不宜解讀為焦慮是求助行為的唯一或主要原因。

### 待你確認

- 第五章原文的「更頻繁」，要確定你的量表測的是求助頻率。如果測的是求助傾向或意願，要改成「求助傾向較高」，否則就是把傾向寫成了行為。
- 第五章的「大學生」只能推到你的樣本範圍。如果樣本來自單一學校或科系，限制要寫明，不要寫成大學生普遍如此。

### 一句話總結

需修（致命 2 處、錯誤 0 處、瑕疵 1 處）。第五章改回與前兩章一致的「影響」，並拿掉「導致」和「主要原因」就能過關。
