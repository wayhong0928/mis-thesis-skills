# 因果用詞檢查

最大的問題在第五章。三段的因果強度一路升高：第一章「影響」→ 第四章「顯著正向影響」→ 第五章「導致」「主要原因」。但這份研究是橫斷面問卷，資料本身撐不起「導致」這種因果說法。

## 第一章：問題不大，建議收斂

「影響為何」在 SEM 文獻中很常見，但它預設了因果方向。有兩種改法：

- **保守寫法**：本研究欲探討：大學生的科技焦慮與其生成式AI求助行為之關聯為何？
- **保留理論方向**：本研究欲探討：大學生的科技焦慮是否能預測其生成式AI求助行為？

建議用第二種。它保留了壓力因應理論給的方向，又沒有宣稱因果。

## 第四章：數據報告正確，用詞可調整

有兩點要注意：

1. **「影響」**：PLS-SEM 的路徑係數只代表「在模型假設下的方向性關聯」。控制性別、年級和程式經驗，只是排除了這三個干擾因素，並不等於確立因果。建議改成「正向預測」或「正向關聯」。
2. **理論與證據的分工**：方向性來自壓力因應理論，不是來自資料。文字上最好讓讀者看出這一點。

**修改建議：**
> 本研究為橫斷面問卷調查（N = 298）。依據壓力因應理論建立模型，以 PLS-SEM 分析並控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向預測效果（β = .29, p < .001）。

另外，PLS-SEM 的顯著性通常來自 bootstrap，建議補上 bootstrap 次數和 95% 信賴區間，也一併報告 R² 或 f²。這些數字在第五章修改時也用得到。

## 第五章：問題最嚴重，必須修改

| 用詞 | 問題 |
|---|---|
| **導致** | 強因果用詞。橫斷面資料無法確立時間先後，也無法排除反向因果。例如：學生常用 AI 求助後，發現自己不懂程式而更焦慮。 |
| **主要原因** | 有兩個問題。一是因果宣稱；二是「主要」沒有證據支持，因為模型沒有和其他預測變項比較相對重要性。β = .29 屬於小到中等的效果，大部分變異仍未被解釋。 |
| **更頻繁地** | 請確認求助行為的量表測的是「頻率」。如果測的是傾向或意圖，這個說法也不精確。 |
| **焦慮是學生轉向AI的原因** | 還有未測量的第三變項可能同時影響兩者，例如自我效能、課業壓力或學業表現。 |

**修改建議：**
> 本研究發現，科技焦慮較高的學生，其生成式AI求助行為亦較頻繁（β = .29）。此結果與壓力因應理論的預期一致，即焦慮可能促使學生將生成式AI作為一種因應策略。然而，由於本研究採橫斷面設計，無法確立兩者的時間先後與因果方向，亦不能排除反向關係（如頻繁使用AI反而加深對自身能力的焦慮）或未測量之第三變項的影響。

## 建議補充：研究限制

在第五章的研究限制中加一段，說明以下幾點：

- 這是橫斷面設計，結果屬於相關性證據。
- 未來可以用縱貫研究（例如交叉延宕模型）或實驗設計（例如誘發焦慮情境）來檢驗因果方向。

## 原則整理

| 可以用 | 避免使用 |
|---|---|
| 關聯、預測、與……有關、與理論預期一致、可能反映 | 導致、造成、使得、主要原因、證明 |

「影響」介於兩者之間。如果要用，請在方法或限制中清楚說明它指的是模型路徑，不代表因果。
