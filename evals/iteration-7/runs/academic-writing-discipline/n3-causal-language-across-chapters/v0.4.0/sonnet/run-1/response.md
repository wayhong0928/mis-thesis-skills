## 學術寫作品質稽核結果

三段的問題集中在因果強度前後不一致。第四章是合格寫法,第一章和第五章與它不一致。

### 致命(因果動詞越線)

- **第五章**
  - 原句:「本研究發現科技焦慮**導致**學生更頻繁地向生成式AI求助,顯示焦慮是學生轉向AI的**主要原因**。」
  - 問題一:「導致」是排除其他解釋的絕對因果。你的證據是橫斷面問卷加 PLS-SEM,這個設計無法排除倒果為因(常向 AI 求助的人,是否因此更焦慮或更不焦慮?)和未測量的第三變數(例如學業壓力、自我效能)。
  - 問題二:「主要原因」除了因果,還多了比較大小的主張。你沒有比較其他因素的解釋力,β = .29 也無法支持「主要」。
  - 問題三:這與第四章自己的寫法落差很大。第四章用「具有顯著正向影響」,第五章升級成「導致」和「主要原因」,這正是口試委員最會切入質疑的地方。

### 錯誤(前後不一致)

- **第一章**
  - 原句:「科技焦慮對其生成式AI求助行為的**影響**為何?」
  - 問題:「影響」本身可以用,因為你符合三條件(壓力因應理論、PLS-SEM 區分自變項與依變項、控制性別/年級/程式設計經驗)。但第一章的措辭沒有標示這是理論導向的檢驗,而且和第五章的「導致」落差太大。
  - 改法:保留「影響」可以,但全篇要統一。見下方整合修改版。

### 通過項目

- **第四章**:「具有顯著正向影響(β = .29, p < .001)」符合三條件(理論、路徑分析、控制變數),並且把支持條件寫在同一句。這是合格寫法,不要動。
- 沒有發現大陸用語。「橫斷面」「控制」「顯著」皆為台灣慣用。

### 瑕疵(是否修由你判斷)

- 第四章的括號與標點請確認全形一致,例如「(β = .29, p < .001)」的統計括號可保留半形。
- 第五章「顯示焦慮是……」的「顯示」承接的是因果推論,修改後一併換掉即可。

### 整合修改版

【第一章 研究問題】本研究欲回答:大學生的科技焦慮對其生成式AI求助行為是否具有影響?

【第四章 結果】(維持原文,不需修改)
本研究為橫斷面問卷調查(N = 298)。依據壓力因應理論建立模型,以 PLS-SEM 分析並控制性別、年級與程式設計經驗後,科技焦慮對生成式AI求助行為具有顯著正向影響(β = .29, p < .001)。

【第五章 討論】本研究發現,科技焦慮對學生向生成式AI求助的頻率具有顯著正向影響,這與壓力因應理論的預期一致。焦慮較高的學生傾向更頻繁地向AI求助,此結果可能反映學生以AI作為因應科技壓力的方式。惟本研究為橫斷面設計,無法排除反向關係(頻繁使用AI可能改變焦慮程度)或未納入模型的其他變項,因果方向有待縱貫或實驗研究驗證。

### 補充建議

- 第五章若要保留對機制的推論,用「可能反映」「與……一致」這類詞。
- 研究限制一節建議補上「橫斷面設計無法確立因果方向」,讓討論章的保守語氣有出處可回指。
