## 因果用詞稽核結果

三段的動詞要分開看。第一章和第四章都用「影響」，這樣寫可以。第五章的「導致」和「主要原因」講過頭了，而且跟前兩章的寫法對不上，口試委員最可能從這裡追問。

### 致命

**1. 第五章用了「導致」**
- 原句：「本研究發現科技焦慮**導致**學生更頻繁地向生成式AI求助」
- 問題：你的資料是橫斷面問卷（N = 298），沒有操弄變項，也沒有時間先後，所以排除不了另外兩種解釋：
  - **倒果為因**：可能是常向 AI 求助的學生，比較常意識到自己能力不足，焦慮因此升高。
  - **第三變數**：例如程式設計自我效能低，可能同時讓焦慮升高、也讓求助變多。你已經控制了程式設計經驗，但經驗不等於自我效能。

  「導致」的意思是已經排除其他解釋、可以確定因果，這份證據撐不起來。
- 改法：沿用第四章的「具有顯著正向影響」，或改成「科技焦慮較高的學生，傾向更頻繁地向生成式AI求助」。

**2. 第五章用了「主要原因」**
- 原句：「顯示焦慮是學生轉向AI的**主要原因**」
- 問題：這句有兩個地方越線。
  - 「原因」是確定因果的說法，問題跟「導致」一樣。
  - 「主要」需要跟其他預測變項比較，或看解釋量（R²、f²），才能下這個結論。單一路徑 β = .29 只能說明這條路徑顯著，不能說明它最重要。
- 改法：「學生轉向AI的可能因素之一」。你也可以把機制說明交給理論來講，例如：「此結果與壓力因應理論的預期一致，即學生可能將生成式AI視為因應焦慮的資源」。這樣寫，標示出來的是理論的主張，不是你的發現。

**3. 三章的因果強度前後不一致**
- 問題：第一章「影響為何」、第四章「顯著正向影響」，到第五章跳成「導致／主要原因」，主張的強度在討論章突然升高。全篇動詞是否一致，比單獨用哪個詞更容易被抓。修好上面兩處，這個問題也就解決了。

### 瑕疵（要不要修由你決定）

- **第四章句子中段偏長**：「依據……建立模型，以 PLS-SEM 分析並控制……後，科技焦慮……」在主詞「科技焦慮」出現前，先放了三段條件。可以拆成兩句：「本研究依據壓力因應理論建立模型，以 PLS-SEM 分析。控制性別、年級與程式設計經驗後，……」
- **依變項的說法要一致**：第五章寫「更頻繁地求助」，前兩章只寫「求助行為」。如果量表測的是求助頻率，沒有問題；如果測的是求助意圖或求助類型，第五章就不要寫「頻繁」。

### 通過項目

- **第一章**：「……的影響為何？」可以用。你的研究有理論依據（壓力因應理論）、有路徑分析（PLS-SEM）、也有控制變數（性別、年級、程式設計經驗），三個條件都滿足，研究問題用「影響」站得住，跟第四章也一致。
- **第四章**：「具有顯著正向影響（β = .29, p < .001）」是合格寫法，而且同一段交代了理論、分析方法和控制變數，不需要改成「預測」。

### 整合修改版

【第一章】本研究欲回答：大學生的科技焦慮對其生成式AI求助行為的影響為何？（不需修改）

【第四章】本研究為橫斷面問卷調查（N = 298），依據壓力因應理論建立模型，並以 PLS-SEM 分析。控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向影響（β = .29, p < .001）。

【第五章】本研究發現，控制性別、年級與程式設計經驗後，科技焦慮對生成式AI求助行為具有顯著正向影響，即科技焦慮較高的學生，傾向更頻繁地向生成式AI求助。此結果與壓力因應理論的預期一致：學生可能將生成式AI視為因應焦慮的資源。然而本研究為橫斷面設計，無法排除反向關係或第三變數的解釋，未來研究可採縱貫或實驗設計進一步檢驗。

（第五章最後一句的研究限制可以視篇幅移到限制節。不過先在這裡點出來，口試時比較不會被追問。）

### 一句話總結

需修：致命 3 處（集中在第五章），錯誤 0 處，瑕疵 2 處。第一章和第四章的因果用詞都合格。
