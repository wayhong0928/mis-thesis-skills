# 因果動詞紀律與構句原則

## 一、因果動詞紀律

### 1. 核心原則

**「影響」不是橫斷面研究的禁用詞，但要有條件地用，且全篇動詞紀律要一致。**

問卷調查多屬於相關性研究，但只要同時符合以下三個條件，就可以正當使用「影響」：

1. **理論文獻的支持**：依據理論建立變數之間的時間先後與邏輯因果（例如理論指出「工作壓力（因）」會導致「離職傾向（果）」），而不是憑資料本身反推因果。
2. **迴歸／路徑分析的應用**：用迴歸分析或 SEM 明確區分自變數（原因）與依變數（結果），並用標準化迴歸係數（β 值）呈現「驅動」關係。
3. **控制變數的介入**：模型中納入性別、年齡等背景變數，扣除干擾後主要變數仍顯著。

三個條件都滿足時，「具有顯著正向影響」「是重要的預測因子」「具備解釋力」都是安全、專業的寫法，不需要一律退回「預測」。

但仍有兩條紅線：

- **避免寫成絕對因果**：不要寫「A 導致了 B 的發生」這類排除掉其他解釋的確定性因果陳述——橫斷面資料存在倒果為因的風險（到底是滿意度高導致忠誠度高，還是本來就忠誠的人看什麼都滿意？）。「導致」暗示的因果強度比「影響」高得多，門檻也該更高。
- **全篇動詞紀律要一致，比用哪個詞本身更重要**：研究問題寫「影響」、結果章卻寫「正向預測」，或同一句話前半段用因果語言、後半段又退回相關語言，這種前後不一致才是口試委員真正會切入質疑的地方。

先分清楚研究要回答的是什麼：問題是「改變 X，Y 會不會因此改變」，主張的是**影響／因果**；問題是「已知 X，能否更準確推估 Y」，目標是**預測**。兩者都可能用迴歸，卻需要不同的設計與驗證方式。三個條件不滿足時（例如沒有理論依據、只是資料裡兩個變數相關、沒控制其他變數），才需要退回「預測」「相關」這類較保守的用詞。

| 比較面向 | 影響／因果 | 預測／相關 |
|---|---|---|
| 核心問題 | 改變 X 是否會導致 Y 隨之改變 | X 是否有助於推估未知或未來的 Y |
| X 的角色 | 對應清楚界定的處置、暴露或介入比較 | 可以是原因、共同原因或代理指標，不必造成 Y |
| 主要證據 | 能支持因果識別的研究設計與明確假設 | 樣本內關聯，以及適用時的樣本外預測表現 |
| 常用方法 | 隨機實驗、準實驗，或具充分識別假設的觀察研究 | 相關分析、迴歸與機器學習 |
| 可以主張 | 「介入 X 會改變 Y」 | 「X 與 Y 相關」或「X 可預測 Y」 |

因果推論不只看 X 與 Y 是否一起變動，還要建立時間次序，並處理兩種常見替代解釋：Y 先改變 X（倒果為因）；或遺漏的第三變數 C 同時改變 X 與 Y。縱貫資料能確認先後次序，但不會自動排除未測量混淆、樣本選擇或時間變動的共同原因——看到 X 先於 Y，只完成因果論證的一部分。

**兩個經典反例**：
- 夏季冰淇淋銷量與溺水事件同時增加，不能推出「吃冰淇淋造成溺水」；高溫是合理的第三變數。
- 公雞啼叫常發生在日出前，能協助預測日出，但阻止啼叫不會阻止日出——先發生與預測準確都不足以建立因果。

**高預測力不能替因果設計補票**：路徑係數顯著、模型樣本外表現良好，都不能單獨證明 X 造成 Y。模型可能只是抓到穩定的代理指標或共同原因。

### 2. 完整替換表（橫斷面研究專用）

| 詞 | 狀態 | 說明 |
|---|---|---|
| 導致 | 門檻最高，通常仍應避免 | 暗示排除其他解釋後的確定性因果，改用「正向預測」「與……正相關」，若三條件都滿足也可退而求其次改「具有顯著正向影響」 |
| 影響 | **有條件可用（見上方三條件）** | 三條件滿足：可用「具有顯著正向影響」「是重要的預測因子」。三條件不滿足：改「正向預測」「與……相關」 |
| 造成 | 門檻高，多數情況避免 | 因果意味強，改「與……相關」，三條件滿足時也可改「具有顯著影響」 |
| 引發 | 視情境 | 描述機制對應關係時，改「對應」「伴隨」 |
| 決定 | 避免 | 「決定」暗示充分條件，改「預測」 |
| 促使形成 | 避免 | 「促使」指定了施動者與因果方向，改「正向預測……的形成」 |
| 讓……變得 | 避免 | 「讓」指定了施力方向，改「與……的提升相關」 |
| 演變為 | 避免 | 「演變」暗示時序，改「轉向」「轉變為」 |
| 固化為 | 避免 | 「固化」暗示不可逆的時序過程，改「逐漸轉變為」「正向預測」 |

### 3. 兩個例外

**例外一：引用具可信因果識別策略的研究時。** 原作者若以隨機實驗、可信的準實驗或其他可辯護的識別策略支持因果主張，引述其發現可依證據強度使用因果語言。例：「⟨作者⟩（年）的隨機實驗發現，實驗組的知識內化顯著低於對照組。」

**例外二：陳述理論主張時。** 理論本身可以是因果主張，但要標示這是理論的主張而非你的發現。例：「⟨某理論⟩主張行為可能逐步轉為習慣」，而不是「⟨某理論⟩指出行為會固化為習慣」（除非已有足以支持這項因果主張的實證證據）。

### 4. 主張強度與證據強度的匹配

| 你手上的證據 | 適用的動詞強度 | 範例句型 |
|---|---|---|
| 自己的橫斷面路徑係數 | 預測、相關 | 「X 正向預測 Y（β = .37, p < .001）」 |
| 自己的實驗（有操弄與隨機分派） | 影響、導致 | 「操弄 X 導致 Y 顯著提升」 |
| 引用具可信因果識別策略的研究 | 影響、導致、發現 | 「⟨作者⟩發現實驗組的遷移表現顯著較差」 |
| 引用別人的橫斷面 | 預測、相關 | 「⟨作者⟩發現 X 顯著預測 Y」 |
| 引用未另具因果識別策略的縱貫研究 | 先於、預測後續變化、與後續變化相關 | 「⟨作者⟩的縱貫追蹤發現 X 先於 Y」 |
| 理論推論（無直接實證） | 暗示、可能、或許指向 | 「這暗示 X 可能與 Y 的形成相關」 |
| 你自己的理論主張（假說推導） | 主張、預期、假定 | 「本研究主張 X 正向預測 Y」 |

### 5. 常見越線情境

| 情境 | 錯誤寫法 | 修正 |
|---|---|---|
| 報告自己的路徑係數，且無理論／控制變數支持 | 「X 導致 Y 的增加」 | 「X 正向預測 Y（β = .37）」 |
| 報告自己的路徑係數，且有理論依據＋控制變數 | 「X 導致 Y 的增加」 | 「X 具有顯著正向影響（β = .37，控制年齡與性別後仍顯著）」——用「影響」而非「導致」，且附上支持條件 |
| 文獻回顧中描述橫斷面研究 | 「⟨作者⟩證實 X 導致 Y」 | 「⟨作者⟩發現 X 顯著預測 Y」（除非原作者本身有可信因果識別策略，見上方例外一） |
| 討論章推論機制 | 「這說明 X 會引發 Y」 | 「這與 X 正向預測 Y 的假設一致」 |
| 同一句話內因果與相關語言並存 | 「X 對 Y 具有顯著之影響，因此可知兩者存在正向關係」 | 全句統一：若條件滿足，「X 對 Y 具有顯著正向影響」；不滿足則「X 正向預測 Y」——**不要一句內兩種語言都用**，這比單獨用哪個詞更容易被口試委員抓到 |

**不要自創路徑名稱**：把路徑、效果、現象包裝成看似已建立的構念（例如「⟨某某⟩侵蝕路徑」「⟨某某⟩固化路徑」這類詞）是學術寫作中不應出現的自創術語。正確做法是用描述性語言：「X 對 Y 的直接效果」「M 的中介效果」「兩者串接後的序列中介效果」。

## 二、句子的構句原則

以簡御繁是總綱：論文內容已經夠複雜，構句與用字要讓骨架明確，不增加讀者負擔。

### 1. 一句一話題

中文是話題凸顯語言，每個句子先確立話題（什麼），再以話題為中心展開陳述（怎麼樣）。**話題一轉移，就斷句**——下句以句號另起，必要時重複關鍵詞重啟話題。這條不等於「句子要短」：同一話題內可以用長句加逗號推進，判準是話題有沒有轉移，不是句子長短。

- ❌「⟨概念 A⟩是⟨定義⟩的傾向，這種傾向在長期後會強化⟨概念 B⟩，而⟨概念 B⟩一旦形成又會回過頭來加深對⟨概念 C⟩的依賴，最終使得使用者難以獨立完成任務。」
  （一句到底，話題從⟨概念 A⟩漂到⟨概念 B⟩再漂到⟨概念 C⟩）
- ✅「⟨概念 A⟩指⟨定義⟩。這種傾向在長期後會強化⟨概念 B⟩，而⟨概念 B⟩一旦形成，又會回頭加深依賴。」
  （斷句、每句話題明確）

### 2. 避免中間肥大

病徵：話題已出現、主要動詞還沒到，中間塞進一大串修飾、條件或原因。最容易引爆的三個句型——「由於……因此」「對於……的問題」「在……的情況下」。

- ❌「本研究針對使用⟨工具⟩且每週使用時數超過十小時的⟨對象⟩在⟨變項⟩上的表現進行分析。」
  （主語中間塞了超長修飾，讀者一口氣下不去）
- ✅「本研究的對象是使用⟨工具⟩的⟨對象⟩，且每週使用超過十小時。本研究分析這群人的⟨變項⟩表現。」

「由於 A，因此 B」若 A 很長，改成「A。基於此，B」，先把因說完再帶出果。

### 3. 還原動詞（戒除弱動詞＋抽象名詞）

弱動詞＋抽象名詞是最常見的歐化語法病灶，遇到就先問能不能還原成單純動詞：

| 弱動詞＋抽象名詞 | 還原為單純動詞 |
|---|---|
| 進行討論 | 討論 |
| 予以分析 | 分析 |
| 加以探討 | 探討 |
| 對 X 進行驗證 | 驗證 X |
| 給予支持 | 支持 |
| 做出貢獻 | 貢獻 |

「存在」濫用也屬於同一類問題：「兩者之間存在顯著關係」改成「兩者顯著相關」；「有很多問題存在」改成「問題很多」。抽象名詞化主語同理：「資料的收集」改成「收集資料」，「理論的建構」改成「建構理論」。

### 4. 被動語態規則

中文以主動為常態，被動是例外：

- **緒論／文獻回顧／討論**：避免「被認為」「被視為」濫用，改回主動陳述。
- **研究方法／結果**：描述程序與分析時，被動語態是學術慣例，可以使用（例如「資料以 SmartPLS 進行分析」）。

判準：這句話的主詞是「做動作的人／研究者」還是「被處理的資料／程序」？後者放行被動，前者改回主動。
