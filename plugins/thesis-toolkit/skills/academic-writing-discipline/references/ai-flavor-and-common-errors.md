# 去 AI 感與常見錯誤速查

## 一、去 AI 感

### 1. AI 生成文本的典型特徵

單獨出現不一定有問題，但多個同時出現就會被懷疑：

| 特徵 | 具體表現 | 修正方向 |
|---|---|---|
| 句長高度一致 | 每句 20–28 字，缺乏長短交錯 | 刻意插入極短句（5–12 字）與長句（35+ 字） |
| 每段結構雷同 | 「主張→證據→小結」的三明治反覆出現 | 至少 1–2 段不收束，讓觀察自然懸掛 |
| 清單式論述 | 「首先…其次…最後…」連用超過三段 | 改用其他結構，或只列兩條精寫 |
| 連接詞過度工整 | 每段開頭必有「此外」「然而」「因此」 | 偶爾不用連接詞，直接陳述 |
| 修辭反覆使用 | 「不是 X 而是 Y」句型反覆出現 | 每份檔案最多一次 |
| 破折號過多 | 中文學術文幾乎不用破折號插說 | 改逗號、括號或拆句 |
| 空泛的讚揚式結語 | 「具有重要意涵」「填補了研究缺口」 | 寫出具體的意涵或缺口內容 |
| 術語不一致 | 同一構念在不同段落用不同名稱 | 學術論文要求全篇統一一個譯名 |
| 缺乏具體數據 | 引用文獻時只說方向，不附 β 或 p 值 | 補上關鍵統計數據 |
| 同義詞輪盤 | 三句內用「主角／核心／關鍵」描述同一件事 | 選一個用到底 |
| 意義膨脹 | 「劃時代的」「具有深遠的影響」 | 改為具體事實 |
| 過度 hedging | 「可能或許大概也許」四連疊 | 選一個，最多兩個 |

### 2. 把形容詞拿掉，論點還站得住才算數

> 以理服人：論述靠證據與推理相符，不靠形容詞。

膨脹詞拿掉後論點如果站不住，那就是論點本身有問題。

| 膨脹寫法 | 具體寫法 |
|---|---|
| 具有重要的理論意涵 | 補上了⟨某段機制⟩的實證缺口 |
| 填補了研究缺口 | 過去研究以⟨A⟩為中介，本研究以⟨B⟩取代 |
| 奠定了重要基礎 | 為後續縱貫設計提供了可檢驗的序列結構 |
| 開啟了新的可能 | ⟨具體做法⟩可以區分是⟨機制一⟩還是⟨機制二⟩ |

### 3. 一個界線必須劃清楚的問題

**去 AI 感有兩種完全不同的動機：**
- **正當**：把初稿改得更有觀點、更精確、更像研究者自己的聲音。這是文字品質的提升，跟用不用工具無關。
- **不當**：用同義詞替換、打亂語法來刻意規避 AI 偵測或抄襲檢測。這在多數學校視為學術不誠實。

**降低機器味不等於能規避檢測。** 改寫工具與 AI 偵測器都不能代替學術誠信判斷；研究者應保存自己的研究與修訂紀錄，並依適用政策揭露工具使用。兩邊都不可靠，正好說明為什麼不該把賭注押在這裡。

**自我測試**：一段論述經過改寫後，如果**你自己講不清楚它的邏輯**，代表這段內容本質上還不是你的知識。此時該做的不是繼續潤飾，而是退回去重新消化文獻與資料。

## 二、常見錯誤速查表

| 錯誤 | 正確 | 類型 |
|---|---|---|
| 數據收集 | 資料蒐集 | 大陸用語 |
| 被試 | 受試者 / 填答者 | 大陸用語 |
| 回歸分析 | 迴歸分析 | 大陸用語 |
| 信息 | 資訊 | 大陸用語 |
| 通過問卷 | 透過問卷 | 大陸用語 |
| 結果表明 | 結果顯示 / 分析結果發現 | 大陸用語 |
| 筆者認為 | 本研究認為 / 研究者認為 | 過於老派 |
| 「」和 " " 混用 | 統一用「」 | 格式不一致 |
| 同一構念交替使用兩個譯名 | 全篇統一一個譯名 | 術語不一致 |
| 每段都以「Author (Year) 指出…」開頭 | 最多連續兩段 | AI 感 / 流水帳 |
| 「具有重要的理論意涵」 | 說清楚對誰、為何重要 | 空話 |
